이번 세션에서 수행한 작업을 작업일지에 기록하세요. $ARGUMENTS

1. 루트의 `MazicAlign_작업일지_*.txt` 중 가장 최신 파일을 찾아 형식을 확인
2. `git status`와 이번 세션의 작업 내용을 바탕으로 오늘 날짜 항목 작성:
   - 기존 형식 유지: `YYYY-MM-DD | 작업 제목` 헤더 + 파일별 [완료]/[신규] 목록
   - "[2] 현재 상태" 섹션의 날짜와 내용도 함께 갱신
   - "[3] 앞으로의 계획"에서 완료된 항목이 있으면 반영
3. 날짜가 파일명(`_YYYYMMDD`)과 크게 벌어졌으면 새 파일 생성 여부를 사용자에게 확인
