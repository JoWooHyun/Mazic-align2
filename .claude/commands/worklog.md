이번 세션에서 수행한 작업을 작업일지에 기록하세요. $ARGUMENTS

1. 작업일지는 **월별 파일** `MazicAlign_작업일지_YYYYMM.txt`(리포 루트, 2026-10-08 분할). 오늘 달 파일이 없으면 새로 만든다:
   - 직전 달 파일의 머리(구분선·"파일:"·"범위:"·"프로젝트:" 줄)를 복사해 파일 이름·범위를 바꾸고 `[1] 날짜별 작업 내역` 부터 시작
   - **[2] 현재 상태·[3] 앞으로의 계획·[4] 기술 스택은 최신 달 파일에만** 둔다 — 새 달 파일을 만들면 직전 달 파일에서 그 절을 잘라 옮기고,
     직전 달 파일의 머리 "※" 줄을 "이 파일은 [1]만 … 최신 달 파일(…)" 문구로 바꾼 뒤 `END OF DOC` 로 닫는다
2. `git log`·`gh pr list`와 이번 세션의 작업 내용을 바탕으로 오늘 날짜 항목 작성(해당 달 파일의 [1] 끝에):
   - 기존 형식 유지: `YYYY-MM-DD | 작업 제목` 헤더 + PR 번호·파일별 [완료]/[신규] 목록
   - "[2] 현재 상태"는 **짧은 요약(기준 커밋·품질 기준선·열린 PR) + 최신 인수인계·로드맵 링크만** 갱신 — 상세 내용을 옮겨 적지 않는다(중복 관리 방지, 2026-10-01 D7)
   - "[3] 앞으로의 계획"은 로드맵 최상단 "0. 11월 데모" 절 링크로 대신하고, 완료 표시만 반영
3. 달이 바뀌었는데 새 달 파일이 없으면 1번대로 만들고, 같은 PR 에 둘 다 포함
