## 1. 옛 엔진 (③ Support 탭, ② Dental "검출 영역")

**"바둑판을 깔고 아래에서 위로 레이저를 쏜다."**

1. 판단: 모델 바닥 아래에 **4 mm 격자**(접점 간격 기본 4.0, 1.5~15) → 칸마다 위로 레이 → 맞은 면 법선이 아래쪽에서 45°(오버행 임계각, 10~80) 이내면 받칠 곳. 높이 0.5 mm 이하는 건너뜀 (`support/utils/auto-generate.ts:60-94`). 메인 스레드 동기.
2. 접점: 맞은 점을 법선 반대로 0.3 mm 모델 안쪽 (`:89-94`).
3. 기둥: **무조건 수직 직선.** 받침 = 아래 **다른** 모델 윗면 또는 플레이트 Y=0 (`:96-111`). **자기 모델 충돌 검사 없음** → 기둥이 자기 모델 아래쪽을 뚫을 수 있고, 속 빈 모델이면 빈 공간 천장에 기둥이 선다.
4. 형상: 회전체 하나 — 바닥 ⌀1.5 →(3.0 mm) 기둥 ⌀0.8 →(1.0 mm) 팁 ⌀0.4 (`utils/support-render.ts:15-112`). 브릿지 = ⌀1.2 튜브, 모델에 파고든 부분은 manifold 로 잘라냄.
5. 저장: world 좌표, `source:'auto'|'manual'|'bridge'`, `kind` 없음. 모델을 옮기면 좌표를 따라 고친다 (`pages/viewer/hooks/useTransformCommit.ts:229-261`).
6. ③ 은 **씬의 모든 모델** 이 대상.
7. **② 와의 차이**: 같은 격자 엔진이되 지현규 **아일랜드 검출**(`utils/dental/island-detection.ts`, 자체지지각 45° 고정 `components/babylon/dental-actions.ts:311`) 면 위 격자점만 통과 + 마진 결과가 있으면 **마진 가드**(마진선에서 0.5 mm + 팁 지름 안쪽 접점을 최대 30회 밀고, 안 되면 버림 — `utils/dental/margin-guard.ts`, 🔒잠금). 순서: 브러쉬 → 마진 찾기 → 아일랜드 검출 → 버튼.
8. 약점: 4 mm 칸 사이 작은 돌출부(커스프)는 0개가 될 수 있다(S-0 진단, 이력 로드맵 `:297-303`).

## 2. 새 엔진 (① Dental "서포트 생성(재설계)")

**"받칠 곳을 먼저 찾고, 그 자리에 찍고, 기둥 길을 찾는다."** 설계 `docs/설계_서포트재설계_20260720.md`(PrusaSlicer 개념 클린룸), S-4b 부터 조우현(AI dev-cycle) 담당(8/5 이관).

1. 판단(워커 — 진행률·취소): 모델을 층두께마다 잘라 2D 폴리곤 (`support/detect/layer-graph.ts:86-96`).
   - **아일랜드** = 아래층에 전혀 안 붙은 조각 (`:129-146`, 리프트 + 0.2 mm 아래 제외).
   - **오버행** = 아래층 경계에서 r = 층두께 / tan(검출각) 보다 더 나온 부분 (`:147-156`).
2. 접점: 아일랜드 크기별 — 작음 = 중심 1점, 가늘고 김 = 양 끝 2점, 큼 = 3 mm 격자. 오버행은 3D 격자 중복 제거 (`support/detect/place-points.ts`). 그 뒤 아래→위 레이로 표면 스냅(실제 Y·법선), 0.1 mm 안 중복 병합.
3. 기둥 길(충돌 검사 — 링 광선 8개·안전거리 0.5 mm, `support/collision-probe.ts`):
   0) 가까운 점끼리 **기둥 하나로 합류**(다리 45° 이내·15 mm 이하·기둥당 8개) → 1) **수직** → 2) **45° 비켜 가다 수직** → 3) 아래 모델 표면에 **앵커** → 4) 실패는 저장 안 하고 개수 알림.
4. 형상: 부품 STL(구·원뿔·원기둥, `support/parts/` — 자체 생성, CHITUBOX 원본 미사용) 조립. 위부터 앞구슬 ⌀0.4(0.2 mm 침투) → 원뿔 → 뒷구슬 ⌀1.0 → 기둥 ⌀0.8 → 발 원뿔 ⌀1.5·높이 3.0 (`support/assemble-core.ts:567-674`).
5. 저장: **모델 좌표(stl-local)**, `kind:'island'|'slope'`, `routeKind`(bent·joinPillar·anchor). 모델을 **회전·확대·수직 이동하면 삭제 + 안내**(B-1, 수평 이동만 따라감) → **배치 먼저, 서포트 마지막.**
6. 기본값: 팁 반경 0.2, 검출각·리프트는 Support 탭 값(45°, 5 mm), 층두께는 슬라이스 패널 값.

## 3. 같이 쓰면

- 자동 버튼 3개 모두 **"그 모델의 `source:'auto'` 서포트 통째로 교체"** (한 트랜잭션, Ctrl+Z 1회). ③ 은 씬 전체 모델이라 모든 모델의 자동 세트가 바뀐다. 결정 D5 "모델당 자동 세트 하나" (`docs/정리_20261001_종합.md:39`).
- 수동·브릿지는 지워지지 않고 누적. 브릿지가 붙은 자동 점은 남김.
- 저장소·타입은 공유: IndexedDB `supports` 하나, `SupportPointV2` 하나. 렌더는 `kind` 유무로 갈림 (`components/babylon/hooks/useSupportMeshSync.ts`).

## 4. 출력(슬라이스·Task0)

- 모델·서포트를 3D 불리언으로 합치지 않는다. 메쉬마다 단면 → 2D 에서 nonzero 합집합(출력 = `utils/task0/task0-mask.ts`, 픽셀 중심 표본). 서포트가 모델에 박힌 부분은 그냥 합쳐진다.
- 2재료에서 서포트는 항상 재료 A, 겹친 곳은 B 우선.

## 6. 데모 권고 (AI)
