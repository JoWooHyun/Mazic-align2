## 1. 목표

### 최종 목표

DLP/LCD 레진 프린터용 dental STL (인레이 · 모델베이스 등) 을 사용자가 뷰어에서 직접 다루고, **마진 라인 → 브러쉬 영역 → 자동 서포트 → 미지지 지오메트리 (island) 검출** 흐름 하나로 인쇄 준비가 끝나게 만드는 것.

프로젝트 최종 로드맵의 **"2노즐 레진 경로 도포 하이브리드"** 방향과의 연결점 — 마진 라인 · brush 영역 · island 결과가 향후 노즐 경로 생성 (인레이 캡 vs 서포트 노즐 분리) 의 입력이 됨. 마진 안쪽 = 인레이 소재 노즐 영역, 마진 밖 sharp ridge 근처 = 지지 소재 노즐 영역 후보. (개발계획서 원본 확보 후 정합 필요.)

### 이번 단계 범위

세션 내내 정리한 기능군의 안정화:
- **마진 찾기 튜닝 잠금 유지** — 임계 함부로 안 건드림
- **선택 영역 자동 서포트** — 자동 각도 조절 재도입 여부 결정 + 마진 가드 재검증
- **아일랜드 검출** — L=42 누락 케이스 원인 확정 후 targeted fix, cross-section fill 안정화
- **슬라이스 뷰** — 시뮬레이션 정확도 + 키보드 UX 유지

## 3. 구현 계획 (Step 단위)

### Step 1: Island L=42 piece 누락 원인 확정 + targeted fix

- **수정 파일**: `frontend/src/utils/slice-detection.utils.ts`, `frontend/src/components/STLViewer.tsx`
- **변경 내용**:
  1. 사용자가 `debugLayers` 활성 상태로 재시연 → 콘솔 출력에서 5개 원인 후보 중 진짜 원인 확정 (component size / connected 여부 / downFacingOnly 전후 count / fillSkippedRows)
  2. 원인별 targeted fix (예: STL mesh vertex 공유 → narrow neck split 검토 / 4-인접 false-positive → 직접 overlap 만 / downFacingOnly 임계 완화 등). **알고리즘 임계 변경 시 사용자 컨펌 후 진행** (마진 로직처럼 island 도 회귀 위험).
- **수용 기준**:
  - 사진 우측 상단 piece (L=42) 가 마젠타 face overlay 로 표시된다
  - 다른 STL (STL Sample 이민정/홍연제 modelbase + inlay_cad) 6개 케이스 재검출 시 island 개수가 이전 대비 감소하지 않는다 (회귀 없음)

## 5. 검증 방법

담당 영역 작업 후 `npm run dev` (백엔드 :5000 + 프론트엔드 :5173, 항상 백그라운드 기동 — CLAUDE.md 참조) 실행 후 다음 8-스텝 재현:

1. **STL 로드** — `STL Sample/` 폴더의 이민정 modelbase + inlay_cad 3개 파일 import. 뷰어 좌측 리스트에 표시.
2. **플레이트 접촉 색** — 로드 직후 STL 바닥이 플레이트 (Y=0) 에 안착 시 **초록**, 관통 시 **빨강** 오버레이 자동 표시.
3. **브러쉬 색칠** — "브러쉬로 영역 지정" 클릭, 두께 조정, 인레이 마진 근처 색칠. 주황 (`#F5852B`) 로 painted overlay.
4. **마진 찾기** — "마진 찾기" 클릭. 콘솔 `[마진 찾기] 색칠 X면 · 시드 엣지 Y ...` 확인. 초록 튜브 라인이 마진 폐곡선 완성.
5. **Floodfill** — 마진 안 더블클릭 → 내부 전체 주황으로 채워짐 (edgeKeys 경계 차단).
