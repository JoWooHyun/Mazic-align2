# 뷰어 조작 체계 — 기준 문서

- 2026-07-14 조사·확정 (PrusaSlicer 공식 문서 대조, 코드 전수 조사 기반)
- **결정: 카메라 조작은 PrusaSlicer 방식으로 통일** (좌드래그=회전, 우드래그=팬, 휠=줌).
  CHITUBOX는 좌/우가 반대(좌=팬, 우=회전)이나, 현 코드가 이미 프루사 방식 + 3D 툴 다수파 기준.
  치투박스 습관 사용자를 위한 전환 옵션은 필요 시 후속.

## 표준 조작 (P5 이후)

### 카메라 (전 모드 공통)
| 입력 | 동작 |
|---|---|
| 좌드래그 (빈 공간) | 회전 |
| 우드래그 | 팬 (모델 위에서도 — 모델이 움직이지 않음) |
| 휠드래그 | 회전 |
| 휠스크롤 | 줌 |
| **0/1/2/3/4/5/6** | Iso/Top/Bottom/Front/Back/Left/Right 뷰 (프루사 동일) |
| **Z** | 선택 화면맞춤 — 선택된 모델만 꽉 차게. 선택 없으면 전체 맞춤 (폴백) |
| **B** | 플레이트 전용 뷰 — 홈(iso) 각도로 빌드 플레이트 전체 프레이밍 |

### 모드별 고유
| 입력 | Select | Support | Dental |
|---|---|---|---|
| 좌클릭 | 선택 (Ctrl=다중) | 서포트 추가/선택 | 색칠 1점 (Ctrl=지우개) |
| 좌드래그 (모델) | 모델 XZ 이동 | 카메라 회전 | 브러쉬 스트로크 |
| 우클릭 (짧게) | 컨텍스트 메뉴: 삭제 / 복제 / 줌투핏 | — | — |
| 더블클릭 | 회전 기즈모 진입 | 브릿지 변곡점 추가 | 마진 안 채우기 |
| Shift+휠 | (줌) | (줌) | 브러쉬 두께 |
| M / R / S | 이동/회전/크기 도구 | — | — |
| Esc | 선택 해제 (단계적: 브릿지 취소→서포트→모델) | 〃 | 〃 |
| Delete | 선택 삭제 | 변곡점>서포트 삭제 | — |
| Ctrl+Z/Y, Ctrl+A/C/X/V | undo/redo, 전체선택/복사/잘라내기/붙여넣기 (공통) | | |

- 우클릭은 짧게 눌렀다 떼면(이동량<5px) 컨텍스트 메뉴, 끌면 카메라 팬이다(프루사 동일).
- 복제는 Ctrl+C 클립보드를 건드리지 않고 선택 모델을 원본에서 XZ +5mm 오프셋해 " 사본" 접미사로 추가한다.

## 프루사 대비 잔여 격차 (후속 백로그)
- **P5 우클릭 컨텍스트 메뉴** (삭제/복제/줌투핏) — 완료 (Z/B 정밀 의미 동승: Z=선택 화면맞춤, B=플레이트 전용 뷰).
- 화살표 키 모델 이동, I/O 키 줌 — 필요성 관찰 후
- Ctrl+좌드래그가 팬(Babylon 기본)인 것 — 프루사는 회전. 실사용 혼란 관찰 후 판단

## 검수(PR #34)에서 나온 엣지 — P5 사이클에서 처리
- (처리 완료) 프린터 프로파일 / GitHub 다이얼로그가 열린 채 Esc → 다이얼로그만 닫히고 뒤의 선택은 유지. 뷰어 Esc 핸들러에 다이얼로그 열림 가드(early-return) 추가.
- (처리 완료) 브릿지 변곡점/끝점 sphere가 우드래그로 끌리던 문제 → sphere PointerDragBehavior 에 `dragButtons=[0]` 적용(모델 메쉬와 동일). 좌드래그만 이동, 우/휠은 카메라로 통과.
