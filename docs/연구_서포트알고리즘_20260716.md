## 0. 세 줄 요약

1. 레진 서포트를 자동 생성하는 **참고 가능한 오픈소스는 사실상 PrusaSlicer 하나**뿐이고, AGPL이라
   **코드는 한 줄도 못 가져온다. 개념과 수치는 배워서 우리가 새로 구현하면 안전하다.**
2. 프루사의 구조는 명쾌하다: **"점 찍기(어디를 받칠까)"와 "구조물 만들기(어떻게 받칠까)"를
   얇은 인터페이스(서포트 점 목록)로 분리** — 이게 지현규(배치 판단)/유승제(구조물 생성) 분담과 정확히 일치한다.
3. 조우현이 궁금해한 것들의 답: **모양** = 뾰족한 화살촉 접점(팁 0.4mm)+기둥(1mm)+바닥판,
   **꺾이는 각도** = 시스템 전체가 단일 45° 한계로 통일, **들어가는 깊이** = 0.2mm 침투.

## 1. 레진 서포트의 개념 모델 (프루사 파이프라인 5단계)

레진(바닥→위로 굳힘)에서 서포트가 필요한 이유 두 가지:
- **아일랜드**: 어떤 층에서 처음 등장해 아래층과 연결이 없는 "공중에 뜬 조각" — 안 받치면 레진 통에 떠내려감
- **오버행**: 아래층보다 바깥으로 튀어나온 가장자리 — 휘거나 처짐

프루사는 이를 5단계로 처리한다:

```
① 모델 슬라이스 → ② 서포트 점 생성 → ③ 서포트 트리(구조물) 생성 → ④ 패드(바닥판) → ⑤ 서포트도 같이 슬라이스해 마스크에 합성
```

### ② 점 생성 — "어디를 받칠까" (지현규 영역과 접점)

- 3D 메시가 아니라 **이미 슬라이스된 2D 층 폴리곤**을 아래→위로 훑는다.
  층간 폴리곤 겹침을 그래프로 연결 → "아래층과 안 겹침 = 아일랜드", "겹치지만 새로 튀어나옴 = 오버행" 분류.
- **밀도는 물리 시뮬레이션이 아니다**: 각 서포트 점이 "지지 반경"을 갖고, 점에서 위로 멀어질수록
  반경이 커지는 **경험 곡선** 하나로 결정한다: `(반경mm, z거리mm) = (3.2,0)→(4.0,3.9)→(5.0,15)→(6.0,40)`.
  새 오버행 지점이 기존 어떤 점의 지지 반경에도 안 들면 거기 새 점을 찍는다. 그게 전부다.
  (프루사도 2.9.0에서 힘/모멘트 누적 모델을 **버리고** 이 방식으로 재작성했다 — 단순한 쪽이 이겼다)
- **아일랜드는 크기별 3분기**: 소형=중심 1점 / 가늘고 긴 것=양끝 2점 / 큰 것=가는 부분(뼈대 따라)+굵은 부분(둘레+내부 격자).
  판정 도구는 보로노이 스켈레톤(뼈대)의 최장 경로. 경계 수치(1.65mm에서 1점 한계 등)는
  **"0.4mm 팁으로 실제 인쇄해 버티는 한계를 실측"한 회귀값** — 이 순서(실험→식)가 중요하다.
- **반도(peninsula) 개념**: 한 층에서 2mm 이상 튀어나온 큰 오버행은 가장자리만이 아니라 내부도 받친다.
- 오버행 윤곽은 2mm 간격 샘플링. 수동으로 찍은 점은 주변 자동 밀도에 영향을 준다(중복 방지).
- 결정론적(같은 입력=같은 결과), 점 타입 구분(island/slope 등).

### ③ 구조물 생성 — "어떻게 받칠까" (유승제 영역)

- **접점(핀헤드)**: 앞구슬(팁 ⌀0.4mm) + 원뿔 + 뒷구슬(⌀1mm) 화살촉 형상.
  앞구슬이 모델 표면 **0.2mm 파고듦**(침투). 방향은 표면 법선을 따르되 **수평 45°보다 눕지 못하게** 포화.
- **기둥**: 핀헤드에서 수직 하강 → 바닥. ⌀1mm.
- **꺾임 각도 = bridge_slope 45° 단일 파라미터**: 다리 기울기, 핀헤드 각도 상한, 기둥 연결 지그재그,
  트리 병합 원뿔각까지 전부 같은 45°를 쓴다. 설계 단순화의 모범.
- **3단 폴백**: 수직 하강 → 45° 경사 다리로 옆으로 피해 하강 → 그래도 안 되면
  **뒤집힌 핀헤드로 모델 표면에 안착**(단, 그 가지에 실리는 총량 상한 10mm).
- **충돌 회피**: 정밀한 부피 검사 대신 **막대 원주를 따라 광선 8~16개 + 안전거리 0.5mm** 레이캐스팅. 실증된 근사.
- **좌굴 방지 규칙**: 기둥 높이 15mm↑면 이웃 1개, 35mm↑면 2개와 지그재그/십자 다리로 연결.
- **Branching 트리(실험적 대안)**: 점들을 높은 것부터 45° 원뿔 안에서 Y자로 계속 병합, 가지가 모일수록 굵어짐.
- **패드**: 서포트 발밑 실루엣을 오프셋해 두께 2mm 판으로 돌출.

### 프루사 주요 기본값 표 (실소스 확인값)

| 파라미터 | 기본값 | 의미 |
|---|---|---|
| support_head_front_diameter | **0.4mm** | 접점 팁 지름 |
| support_head_penetration | **0.2mm** | 모델 침투 깊이 |
| support_head_width | 1.0mm | 접점 길이(구슬 중심 간) |

## 4. MazicAlign 재설계 제안 (S-3 설계서의 뼈대)

### 4-1. 채택할 개념 (프루사에서 배운 것, 자체 구현)

1. **인터페이스 = 서포트 점 목록** `{위치, 팁 반경, 타입(island/slope/manual)}` —
   지현규(검출→점 배치)와 유승제(점→구조물)의 분담 계약. ADR-3 파이프라인 유지, 내용물 교체.
2. **2D 층 그래프 자료구조**: 층 폴리곤 + 층간 겹침 링크로 아일랜드/오버행/반도 분류.
   우리 SliceEngine이 이미 층 폴리곤을 만들므로 접목 자연스러움.
   (현 v2의 문제였던 "전역 격자 필터링" 방식은 폐기 — `docs/진단_아일랜드서포트_20260715.md`)
3. **밀도 = z거리→지지반경 경험 곡선** (힘 모델 불채택 — 프루사도 버림). 곡선 값은 우리 레진으로 실측해 재조정.
4. **아일랜드 크기별 3분기** (1점/2점/thin·thick). 1차 버전은 보로노이 대신 근사(최대내접원/bbox)로 시작 가능.
5. **접점 = 화살촉(앞구슬+원뿔+뒷구슬) + 침투 깊이 파라미터. 각도는 단일 45° 한계로 전 시스템 통일.**
6. **3단 폴백** (수직→경사 다리→모델 안착+무게 상한) + **원주 레이캐스팅 충돌 회피** (Babylon 레이 또는 자체 BVH).
7. **기둥 상호 연결 규칙** (15/35mm 높이 기준 지그재그/십자).
8. Rahm식 **2단 각도(선호/최대 분리)** — 프루사엔 없는 개선 아이디어로 검토.
9. UI: 4분절 파라미터 + 프리셋 3종 (치투박스 관례 = 기존 UI 규칙과 일치).

### 4-2. 결정해야 할 것 (S-3에서, 유승제와 함께)

- 기둥형(프루사 Default)부터 할지, 트리형(Branching/Rahm)을 처음부터 노릴지
  → **권고: 기둥+경사다리(Default형) 먼저.** 단순하고 검증됐고, 치과 모델(낮고 면적 넓음)에 충분. 트리는 2차.
- 치과 특화 기본값: 프루사 범용값(팁 0.4)과 Ackuretta 치과값 중 어디서 출발할지 → 실측 실험 계획 필요
- 접점 실험: "우리 레진·프린터로 팁 지름별 버티는 한계 길이" 실측표 (프루사의 상수 결정 순서를 따름)
- 기존 disc 서포트(PR #19)와의 관계: 대체인가 병존인가
- top-down 프린터 특성 반영: 프루사는 bottom-up 기준 — 박리력 등 힘 방향이 다르므로 밀도 곡선·팁 강도의
  실측 재조정 필수 (개념 구조는 동일하게 유효)

### 4-3. 잠정 구현 단계 (S-4 분할 초안)

1. 층 그래프 + 아일랜드/오버행 분류 (검출 재정비 — 지현규 영역 접점, 기존 마진 잠금은 불변)
2. 서포트 점 생성기 (지지반경 곡선 + 아일랜드 3분기) → 점만 뷰어에 표시해 검증
3. 구조물 생성기 (핀헤드+기둥+경사다리+충돌회피) — 유승제 주도
4. 패드/래프트 + CTB/마스크 합성 배선
5. UI (4분절+프리셋) + 수동 편집(점 추가/삭제)과 자동 밀도 연동

## 5. 미확인/한계

- 프루사 구버전(≤2.8) 힘 모델 세부 (히스토리 미포함 — 현행 방식이 더 단순하므로 무시해도 됨)

- top-down 방식 특유의 서포트 문헌은 별도 조사 필요 (대부분 자료가 bottom-up 기준)
