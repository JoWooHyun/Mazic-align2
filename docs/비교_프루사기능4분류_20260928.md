## 1. 우리만 있는 것 (프루사 없음)

| 기능 | 비고 |
|---|---|
| 마진(변연) 검출 + 마진 안 자동 채우기 | 치과 차별점. 잠금 알고리즘 |
| 아일랜드 검출 → 검출 영역 자동 서포트 | 프루사 SLA 는 오버행 점 생성만. "아일랜드" 개념·마진 가드 없음 |
| 브러쉬→마진→아일랜드→서포트 원클릭 흐름 | 조합 자체가 우리 것 |
| 하이브리드 출력(층별 마스크 + 도포 G-code, 층 내 T0/T1) | 프루사는 FDM 또는 SLA 택일. 하이브리드 모드 없음 |
| 웹 실행(설치 불요), IndexedDB 로컬 저장 | 배포·협업 |
| Top-down 전용 시간 추정 | 프루사는 bottom-up 리프트 모델 |

## 2. 겹치는 것 — 대등 / 프루사가 더 좋음

| 기능 | 우리 | 프루사 | 판정 |

| 이동·회전·배율 수치 입력 | 슬라이더+숫자, 배율 % | 위치·회전·**크기 mm / %** 토글, world/local 좌표 | **프루사 우위** — 크기 mm 가 없음 (데모 #1) |

| 복제·복사·붙여넣기 | 우클릭 복제, Ctrl 키 복붙(위치 미보존) | 복붙 위치 보존, 인스턴스 | 프루사 우위 |

| 모델 목록 | 파일명·크기·선택·삭제 | 이름 변경·숨김·per-object 설정·modifier | 프루사 우위 |
| 카메라 | 9버튼 + 숫자키 + 커서 줌 | 동일 + 원근/직교 토글 | 대등 |
| 출력영역 초과 | 배너 + 빨간 박스 + 확인창 | 베드 밖 회색 + 슬라이스 차단 | 대등(정책 차이) |
| 자동 서포트(점 생성) | 격자/아일랜드/재설계 3경로, 프리셋 3 | 밀도·최소 점 거리·헤드 지름 + 자동 | 대등. **진입점 3개는 우리 결함** |
| 수동 서포트 편집 | 클릭 추가, 기둥 이동, 브릿지·변곡점 | 점 추가/삭제, 브러시 선택, 헤드 지름 | 대등. 브릿지는 우리만, 브러시 다중선택은 프루사만 |
| 슬라이스 미리보기 | 층 슬라이더, 2D 마스크, 3D 단면 | 동일 + 서포트/패드 포함 미리보기 | 대등 |

| 프린터 프로파일 | 빌트인 3(읽기 전용)·사용자 편집 | 프린터/재료/출력 3계층, 상속, 내보내기·가져오기, 비교 | **프루사 우위** (하이브리드 문서 §3 의 A/B/C 3층과 같은 구조) |
| 프로젝트 저장 | `.mzalign` 코드만 | 3MF 프로젝트(모델+설정+페인팅) | **프루사 우위** — 우리는 미연결 |
| 예제 모델 | 큐브·구 | Shape Gallery (여러 형상·사용자 등록) | 프루사 우위 (효용 낮음) |

## 4. 추천 — 도입할 것 (우선순위)

기준: (1) 하이브리드·치과 핵심에 닿는가 (2) 우리 자산 재활용으로 싼가 (3) "일관성 결함"을 고치는가.

### A. 지금 코드의 결함을 프루사 방식으로 메우기 (기능 추가 아님)

| 순위 | 항목 | 프루사에서 가져올 개념 | 공수 |
|---|---|---|---|
| A1 | **undo 전면화** | 모든 조작을 히스토리에 넣는다: STL 추가·삭제·붙여넣기·복제·dental 칠·파라미터 변경 | M |
| A2 | **프로젝트 저장 연결** (`.mzalign`) | 3MF 프로젝트 = 모델 + 변환 + 서포트 + **설정 + 페인팅**. 저장 안 되는 상태(서포트 파라미터·레이어 두께·dental 칠) 전부 여기로 | S~M |
| A3 | 자동 서포트 진입점 1개로 | 프루사는 "서포트 점 생성" 버튼 하나 + 파라미터 | S |
| A4 | 크기 mm ↔ 배율 % 토글 + 바닥으로 내리기 상시 버튼 | 수치 패널 | S |
| A5 | 기즈모 Shift 스냅 | Babylon `snapDistance` | XS |

### B. 하이브리드 핵심에 직결 (데모 후 P 단계에 편입)

| 순위 | 항목 | 어디에 | 비고 |
|---|---|---|---|
| B1 | **MMU 페인팅 방식** (브러시·Smart fill·관통 옵션 + 마진 안 채우기) | 하이브리드 §5 재료 배정 | 기존 dental 브러시에 재료 채널 추가 |
| B2 | **컷 → 분할 평면** | 하이브리드 §5 보조 도구 | 절단 대신 "이쪽 A / 저쪽 B" 만 |
| B3 | **경로 미리보기(툴별 색)** | P7 2색 프리뷰 | 프루사 G-code 프리뷰의 레이어 슬라이더 + 툴 색 |
| B4 | **프리셋 3계층 + 내보내기/가져오기** | 하이브리드 §3 A/B/C | P1 ⑤ 와 합침 |

## 5. 한 장 요약

> 프루사와 겹치는 영역에서 우리가 지는 곳은 **undo·저장·프로파일·수치 입력** — 전부 "기능 없음"이 아니라 "일관성 없음"이고, A1~A5 로 메운다.
> 프루사에만 있는 것 중 가져올 것은 **MMU 페인팅·컷(분할 평면)·툴별 경로 프리뷰·3계층 프리셋** — 전부 하이브리드 2레진에 직결되며 이미 하이브리드 계획의 P 단계에 자리가 있다.
> 나머지 범용 기능은 데모 목록까지만 하고, E 목록은 안 만든다고 못 박는다.
