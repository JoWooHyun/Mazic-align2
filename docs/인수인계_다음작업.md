2. **충돌 회피** — 막대 둘레 링 광선 8개(접점 주변 16개) + 안전거리 0.5mm.
   **내부 시작 처리 필수**: 광선 시작점이 메시 내부면 관통 후 재발사 (화살촉 0.2mm 침투 전제).
3. **기둥 연결** — 높이 15mm↑ 이웃 1개 / 35mm↑ 2개, zstep=tan(45°) 지그재그, 다리마다 충돌검사, 높이비 50% 규칙.
4. **기둥 공유 (B-3 해소책)** — ⚠️ **프루사는 점마다 기둥을 세우지 않는다.** 지면 직행 가능한 점들을
   클러스터로 묶어 중심 1개만 기둥 + 나머지는 경사 다리 합류. **현재 서포트 1,300개 문제의 정공법.**
5. **꺾임점마다 구(Junction) 삽입** — 다리·기둥 접합 단면 연속성 (S-4b-1 파단 이슈의 일반해).
6. **중복점 제거** — 0.1mm 이내 점 제거 (프루사 전처리).

### 제약

- 형상 = **B안(부품 STL 조립)** 유지. `assemble-core.ts`에 "임의 두 점을 잇는 막대" 조립 추가.
- 마진(margin-detect) 무접촉(잠금) / 기존 서포트 경로(trunk/bridge/manual) 무변경 / 새 파일 500줄 이하.
- 프루사는 AGPL — **개념만, 코드 이식 금지** (정독 문서가 클린룸 스펙 역할).
