## 2. 다음 작업 상세 — S-4b-2

### 무엇을 만드나 (설계서 4-4/4-5/4-6)

정본: `docs/설계_서포트재설계_20260720.md` 4장. 반드시 먼저 읽을 것.

1. **3단 폴백** (기둥이 바닥까지 곧장 못 갈 때 순서대로 물러섬):
   - 1단 수직 하강 (아래 뚫려 있으면 그냥 내림 — 지금 하는 것)
   - 2단 경사 다리로 옆으로 피해 하강 (구조각 45°, 최대 길이 ~15mm)
   - 3단 모델 표면에 안착 (뒤집힌 화살촉, 그 가지에 실리는 총량 상한 ~10mm)
2. **충돌 회피**: 막대 둘레를 따라 광선 8~16개 + 안전거리 0.5mm 레이캐스팅으로 앞이 막혔는지 근사 검사
   → 막혔으면 폴백. (Babylon Ray 또는 자체 구조 — 구현자 판단)
3. **기둥 연결(좌굴 방지)**: 기둥 높이 15mm↑ 이웃 1개 / 35mm↑ 이웃 2개와 지그재그 다리로 연결
4. 모든 꺾임·경사는 **구조각 단일 파라미터**(기본 45°, 사용자 조절) 하나로 통일.

### B안 방식 유지

경사 다리·연결 다리도 부품 STL(cylinder 등)을 **회전 배치**해 조립한다.
→ `assemble-core.ts`에 "임의 두 점을 잇는 막대" 조립(축 정렬 변환)을 추가하는 형태가 자연스러움.
