### 6-1. 새로 드러난 것 [확인]
1. **G-code 가 겹친 솔리드를 구멍으로 만든다.** `polygon-clipper.ts:67` 이 EvenOdd 합집합이라 모델에 박힌 서포트 기둥 자리가 비고, 마스크(NonZero)는 채운다 → "도포 영역 = 경화 영역"이 깨짐. Task0 경로는 NonZero 합집합 필요.
2. **층 수는 실제로 이미 마스크와 같다.** 식은 `ceil+1` 이지만 `break` 로 실제 출력 층 수는 `ceil`. 진짜 차이는 Z 표기(N·lh 대 (N+1)·lh), 자르는 높이(바닥 대 중앙), 기준(모델 최저점 대 플레이트 0), 합집합 규칙.
3. **현 G-code 생성기는 헤드리스 검증 스크립트에서 실행이 안 된다**(js-clipper CJS 문제). 22종 검증 중 생성기를 실제로 돌리는 것은 0. 검증기에 20줄짜리 우회 장치 필요(시험 완료).
4. **마스크 PNG 는 8-bit 회색조가 아니다**(브라우저 RGBA). job.zip 에는 회색조 PNG 인코더와 새 zip 조립기 필요.
5. 출력 가능 영역(X10~150 × Y10~85)은 world 기준 **비대칭**(Z −40~+35). 현 출력영역 검사는 대칭이고 **서포트를 빼고 검사**한다.
6. 현 도포 순서는 "모든 섬 바깥벽 → 다시 첫 섬 안쪽"이라 칠한 영역을 가로지른다. 기본값(인필 100%)이면 줄 채움 없이 동심 루프만 9999회까지.
