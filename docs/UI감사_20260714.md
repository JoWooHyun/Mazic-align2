## 잘된 점

1. **빈 상태 안내가 전 진입점에 존재** — 프로젝트 목록("아직 프로젝트가 없습니다… + New Project 로 시작하세요"),
   좌측 파일 리스트, 뷰어 중앙 오버레이("좌측 '+ 추가' · 상단 'STL 열기' · 드래그") 모두 다음 행동을 명시.
   `01-projects-empty.png`, `03-viewer-empty.png`
2. **위험 조작 보호 일관** — STL 삭제 / 프로젝트 삭제 / 사용자 프로파일 삭제 전부 confirm 확인창.
   (네이티브 confirm 로그 확인: `"denture ivoclar back 4mm.stl" 을(를) 삭제할까요?`)
3. **Dental 흐름의 버튼 가드 논리가 정확** — 색칠 0면 → "마진 찾기" 비활성, 마진 없음 → "마진 지우기" 비활성,
   아일랜드 결과 없음 → "검출 영역 자동 서포트" 비활성. 브러쉬→마진→아일랜드→자동서포트 순서가
   활성/비활성만으로 자연스럽게 유도됨. `11-dental-initial.png`
4. **내보내기 진행/취소 UI** — 진행률 바 + 취소 버튼, busy 중 패널 닫기(×) 비활성, 취소 후 깔끔한 복귀.
   `20-export-progress.png`, `21-export-cancelled.png`
5. **모드별 조작 안내 배너 + 단축키 노출** — 서포트 편집("모델 표면 = 추가 · 기둥 클릭 = 선택 · Delete = 삭제"),
   Bridge/Disc 상태 문구, 브러쉬 활성 시 "Ctrl+드래그 = 지우기 · Shift+휠 = 두께 조절" 안내.
   숨은 기능(SHIFT+휠)이 문서화되어 있음. `06-mode-support.png`, `07-mode-dental.png`
6. **슬라이스 미리보기가 모달이 아닌 사이드패널** — 3D 시점을 유지한 채 레이어 스크럽 가능 (CHITUBOX 감각).
   출력 추정(부피/무게/시간)에 산정 기준(프로파일·노광·밀도)까지 병기. `17-slice-panel.png`

## 빠른 개선 Top 5 (각 반나절 이하)

1. **픽셀 피치 단위 표기 수정** (#6) — FormRow 라벨의 `uppercase` 제거 또는 "(um)" 하드코딩. 몇 분 규모, 오독 위험 제거.
2. **"+ 새 프로파일" 폼 리셋 버그 수정** (#7) — isNew 진입 시 draft/selectedId 경합 정리. 실사용 혼란 직결.
3. **Support 모드 진입 시 우측 패널 자동 전환** (#4) — `EditModeControls onChange`에 한 줄. Dental과 일관.
4. **마진 찾기/아일랜드 검출 버튼 busy 상태 + 실행 전 안내** (#1·#2의 단기 완화) — `autoSupportBusy` 패턴 재사용("검출 중…"), 아일랜드 검출엔 대형 메쉬 경고 문구. 근본 해결(워커 이전)은 별도 과제로 등록 권장.
5. **프로파일 다이얼로그 폼 스크롤 + 진행 표시 "준비 중…"** (#9, #10) — `overflow-y-auto` 한 클래스 + 조건부 문구. 720p 노트북에서 저장 불가 문제 해소.

> 별도 최우선 기술 과제 (Top 5 규모 초과): **아일랜드 검출·마진 찾기의 워커 이전** (#1·#2).
> 실측 353초 프리즈는 기능 미동작으로 인식될 수준 — 기존 slice-batch 워커 인프라(진행률/취소) 재사용 가능.
