# 수동 확인 체크리스트 — "다음에 실제로 눌러볼 것들"

- 작성: 2026-07-09. PR #22~#28이 코드 검증(정적·바이트 대조)은 통과했으나 **실제 화면 조작 확인을 미룬 항목**의 통합 목록.
- 확인 방법: `start-dev.bat` 더블클릭 → 브라우저 `localhost:5173/v2` → 아래 순서대로. 전부 해도 **15분**.
- 결과 기입: 각 항목 ✅/❌ + ❌면 증상 한 줄. 이 파일에 직접 체크하거나 AI에게 결과를 불러주면 됨.
- (실제 프린터가 필요한 검증은 별도 문서 `docs/실기검증계획.md` — 이 문서는 PC만으로 가능한 것들)

## A. 브러쉬/Dental (PR #22 — 카메라·무효화)

STL 로드 후 Dental 모드에서:

- [ ] **A1. 색칠 중 화면 고정**: 모델 표면을 좌클릭 드래그로 색칠 → **색칠만 되고 화면(카메라)이 같이 돌지 않으면 ✅** (수정 전엔 동시에 돌았음)
- [ ] **A2. 화면 회전은 다른 버튼으로**: 같은 모드에서 휠클릭(또는 우클릭) 드래그 → 화면 회전되면 ✅
- [ ] **A3. 더블클릭 채우기 생존**: 색칠 → "마진 찾기" → 초록 라인 안쪽 **더블클릭** → 내부가 주황으로 채워지면 ✅ (수정 과정에서 깨질 뻔했던 기능)
- [ ] **A4. 회전 시 재검출 요구**: 마진 찾은 상태에서 Select 모드로 모델 회전 → **초록 라인이 사라지고** 패널이 초기 상태로 돌아오면 ✅ (의도된 새 동작)
- [ ] **A5. 수치 입력도 동일**: 마진 찾은 상태에서 Transform 패널에 회전값 직접 입력 → 역시 초록 라인 사라지면 ✅
- [ ] **A6. undo도 동일**: 마진 찾기 → 모델 이동 → Ctrl+Z → 초록 라인이 (이미 사라진 상태 그대로) 남지 않으면 ✅
- [ ] **A7. 빠른 연속 조작 (PR #26)**: 색칠하고 **곧바로(0.3초 안에)** "마진 찾기" 클릭 → 초록 라인이 생기고 **사라지지 않으면 ✅** (수정 전엔 방금 만든 결과가 지워질 수 있었음)

## B. 아일랜드/자동 서포트 (PR #24·#25)

- [ ] **B1. 자동 서포트 소진**: 아일랜드 검출(마젠타) → "검출 영역 자동 서포트" 클릭 → 서포트 생성 + **버튼이 비활성으로 바뀌면 ✅** (연타해도 중복 없음)
- [ ] **B2. 다중 STL 정리**: STL 2개 로드 → A에서 마진 찾기 → B 선택해서 마진 찾기 → **A의 초록 라인이 사라지고 B만 남으면 ✅** (수정 전엔 A 것이 유령으로 잔존)

## C. 내보내기 (PR #24·#28)

- [ ] **C1. 취소 버튼**: 마스크 ZIP 내보내기 시작 → 진행바 옆 **취소 버튼**이 보이고, 누르면 조용히 멈추면 ✅ (에러 창 안 뜨는 게 정상)
- [ ] **C2. G-code 무정지 (PR #28)**: G-code 내보내기 → **진행률이 표시되고 그동안 3D 화면을 돌릴 수 있으면 ✅** (수정 전엔 수십 초 멈춤). 취소 버튼도 동작하면 ✅
- [ ] **C3. 실패 안내**: STL 없이(빈 프로젝트) 내보내기 시도 → 조용히 무시되지 않고 **안내 문구가 뜨면 ✅**
- [ ] **C4. G-code 첫 레이어 (PR #22)**: G-code 내보내서 메모장으로 열기 → `; layer 0` 아래에 좌표 명령(G1 X.. Y..)들이 **있으면 ✅** (수정 전엔 첫 층이 통째로 없었음)

## D. disc 서포트 (PR #19 — 유승제 확인과 별개로 동작 확인)

- [ ] **D1. 배치**: Support 모드 → "Disc" 토글 → 표면 클릭 → 원판형 서포트 생성되면 ✅
- [ ] **D2. 추종**: 모델 회전 시 disc가 따라오면 ✅ / Ctrl+Z로 배치 취소되면 ✅
