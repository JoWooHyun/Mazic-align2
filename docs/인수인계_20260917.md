## 5. 새 세션이 알아야 할 함정 (이 세션에서 추가된 것)

기존 함정 목록은 `docs/인수인계_20260904.md` §5 참고. 이번에 추가:

1. **`.parent =` 대입 금지, `setParent()`** (B-32) — CreateDecal 처럼 **월드 좌표로 구워진**
   메시를 부모에 붙일 때 원시 대입은 부모 변환을 이중 적용한다
2. **캔버스 위 바깥클릭은 `pointerdown`으로** (B-33) — Babylon 이 `preventDefaultOnPointerDown`
   기본 true 라 `mousedown` 이 아예 발생하지 않는다
3. **clipPlane 과 같은 평면에 그리는 보조 지오메트리는 부호 확인** (B-34) —
   `y > sliceY → discard` 라 평면 **위**에 그리면 자기 자신이 잘린다
4. **화면 표시와 알고리즘이 같은 좌표계를 쓰는지 주기적으로 대조** (B-35) —
   오버행은 로컬 법선, 검출은 world 법선이라 서로 다른 기준이었다
5. **`window.resize` 만으로는 부족** (B-36) — flex 형제가 늘어 캔버스만 좁아지는 경우를
   못 잡는다. ResizeObserver 로 캔버스 자체를 감시
6. **"A ?? B" 폴백은 A가 항상 정의돼 있으면 사문** (B-31) — 값의 주인을 한 곳으로
   정하고 나머지는 **타입에서 빼서** tsc 가 재도입을 막게 할 것
7. **검증 스크립트는 `npx tsx`로** — plain node 는 ERR_MODULE_NOT_FOUND 오탐.
   판정은 출력 문자열이 아니라 **exit code**로(대조군 스크립트는 정상 단언에도 "FAIL" 문자열 포함)
8. **PR 분할 시 같은 파일의 같은 함수를 건드리면 충돌한다** — 이번에 #90·#91 이 미리보기
   토글 핸들러에서 충돌했다. 분할 전 겹치는 지점을 확인할 것
