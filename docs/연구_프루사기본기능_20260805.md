- 방법: **웹 문서 기반 클린룸 조사** — help.prusa3d.com 공식 문서·매뉴얼·서드파티 가이드만 참고, 소스 코드 미열람 (AGPL 안전선)

## 1. 기능별 조사 결과 (프루사에서의 동작 상세)

### 1-1. 이동 (Move) — 단축키 M, 좌측 툴바 1번
- 선택 오브젝트에 X/Y/Z 축 화살표 3D 위젯 표시. 위젯 없이도 좌클릭 드래그로 XY 평면 이동 가능(툴 비활성 상태에서도).
- **Shift 누르면 1mm 단위 스냅** 이동.
- 오브젝트를 베드 아래로 내리면(sinking) 베드 위 부분만 출력 — 교차선을 흰 외곽선으로 표시. "Drop to bed"(베드에 놓기) 버튼으로 복귀. 이 잠수 기능은 SLA(레진) 모드에서는 비활성 — **레진 슬라이서인 우리에겐 '항상 Z=0 스냅'이 오히려 프루사 SLA 모드와 같은 정책**.
- 우측 패널에 Position X/Y/Z 수치 입력 필드 연동.

### 1-2. 크기 조절 (Scale) — 단축키 S, 좌측 툴바 2번
- 3D 위젯: **모서리 사각형 = 균등(uniform) 스케일**, 각 축 핸들 = 축별(비균등) 스케일. 기본은 중심 기준 대칭 스케일, **Ctrl을 누르고 핸들을 잡으면 한쪽 면 기준(비대칭) 스케일**.
- **Shift = 5% 단위 스냅**. 스케일 툴 활성 중 **F = Scale to fit(베드 최대 크기로 맞춤)**.
- 우측 패널에서 **Scale factor(%)와 Size(mm) 양방향 입력** — 치과에선 mm 절대치가 중요. 균등 잠금 토글, 100% 리셋 버튼(주황 화살표), 축별 미러 버튼 3개.

### 1-3. 회전 (Rotate) — 단축키 R, 좌측 툴바 3번
- 축별 원형 링 위젯. 핸들을 잡으면 눈금 원 표시: **바깥 원 짧은 눈금 = 5° 스냅, 안쪽 긴 눈금 = 45° 스냅** — 눈금 위에 호버하면 연속 회전→이산 스냅으로 전환.
- 우측 패널에 축별 각도 수치 입력 + 회전 리셋 버튼.

### 1-4. 바닥면 지정 (Place on face) — 단축키 F, 좌측 툴바 4번
- 활성화하면 모델의 **평탄면 후보들이 흰 평면으로 하이라이트**되고, 하나를 클릭하면 그 면이 베드에 닿도록 모델이 즉시 회전.
- "임포트 직후 방향이 틀어진 모델을 바로잡는 가장 빠른 방법". 제한: 루트 오브젝트에만 동작(파트에는 불가), 경사면이 많은 모델에선 의도한 면을 못 잡을 수 있음.
- 치과 모델(교합면/베이스 평면이 뚜렷)에 특히 잘 맞는 도구.

### 1-5. 복사/복제/인스턴스
- **Ctrl+C / Ctrl+V**: 완전 독립 복사(모디파이어·서포트 블로커까지 포함해 통째로 복제).
- **인스턴스**: `+` = Add instance, `-` = Remove instance. 우클릭 "Set number of instances"(개수 지정), **"Fill bed with instances"(베드를 최대 개수로 채움 — Arrange의 간격·회전 설정을 그대로 사용)**.
- 인스턴스는 **지오메트리·설정·스케일·방향을 공유(Z축 회전만 개별)** — 하나를 스케일하면 전부 스케일됨. 메모리 절약 + 일괄 편집이 장점. "Set as a separated object" 또는 오브젝트 리스트 드래그로 독립 분리 가능.

### 1-6. 자동 배치 (Arrange) — 단축키 A, 상단 툴바
- **A = 전체 배치, Shift+A = 선택한 것만 배치**(나머지는 위치 유지).
- **아이콘 우클릭 → 설정 다이얼로그**: 오브젝트 간 **간격(gap) 슬라이더/수치 입력**, **Z축 회전 허용** 토글. 이 설정이 Fill bed with instances에도 공통 적용.
- 베드에 다 안 들어가면 베드 밖(가상 추가 베드)으로 밀어냄.

### 1-7. 절단 (Cut) — 단축키 C, 좌측 툴바 5번
- 평면 위젯을 X/Y/Z 이동·임의 각도 회전해 절단 위치 지정. **상부만/하부만/둘 다 유지** 선택. FDM용 도브테일 조인트·커넥터·다웰핀 생성 지원(2.6+).
- 치과 워크플로우에선 우선순위 낮음(모델 절단은 보통 CAD 단계에서 끝남).

### 1-8. 오브젝트 목록 패널 (우측 트리)
- 계층: **오브젝트 → 인스턴스 → 파트/모디파이어/서포트 블로커·인포서 → 오브젝트별 커스텀 설정**. Advanced/Expert 모드에서만 표시.
- **더블클릭 이름 변경**, **눈 아이콘 = 슬라이싱 포함 여부 토글**(꺼도 베드엔 보임), 기어 = 오브젝트별 설정, **느낌표 = 메시 오류 표시(+수리 연동)**, 드래그앤드롭 인스턴스 분리.

### 1-9. 기타 편의
- **Undo/Redo**: Ctrl+Z / Ctrl+Y, 상단 툴바 화살표(히스토리 드롭다운).
- **삭제 Del / 전체 삭제 Ctrl+Del / 전체 선택 Ctrl+A / 해제 Esc**.
- 카메라: 0~6 뷰, Z=줌투핏, B=베드 줌 — **우리 v2와 이미 동일한 체계** (PR #34).
- 베드 밖 오브젝트는 회색 처리 + "outside print volume" 경고 + 슬라이스 버튼 비활성.

### 1-10. UI 구성 — 툴바 배열과 그 이유
- **좌측 세로 툴바 (위→아래)**: Move → Scale → Rotate → Place on face → Cut → (Measure/페인팅 계열…). 앞 5개가 "선택한 오브젝트를 조작하는 배타적 모드 툴"이고 **사용 빈도 순** 배열. 오브젝트 선택 시에만 활성화.
- **상단 가로 툴바 (좌→우)**: Add(가져오기) → Delete → Delete all → Arrange → Copy → Paste → Add/Remove instance → Split → (Variable layer height) → Undo/Redo.
- 즉 **"장면(플레이트) 단위 관리"는 상단, "개별 오브젝트 변형 모드"는 좌측**이라는 명확한 이원화. 단축키도 변형 모드는 단일 키(M/S/R/F/C), 편집 동작은 Ctrl 조합.

## 2. 우리 v2 대비 격차표

| 기능 | 프루사 | 우리 v2 현황 | 격차 |
|---|---|---|---|
| 이동/회전/크기 기즈모 | M/R/S + 스냅(Shift 1mm, 5°/45°, 5%) | GizmoManager M/R/S 있음 (PR #34) | **스냅 증분** 없음(확인 필요) |
| 수치 입력 패널 | Position/Rotation/Scale%/Size mm + 리셋·미러 | 없음 | **큼** |
| Place on face | F, 평탄면 하이라이트 클릭 | 없음 | **큼** |
| 복사 | Ctrl+C/V 독립 복사 | 우클릭 복제 (PR #35) | 단축키·일관성 |
| 인스턴스 | +/-, 개수 지정, Fill bed, 설정 공유 | 없음 | 중간 (개념 자체 부재) |
| 자동 배치 | A/Shift+A, 간격·회전 파라미터 | 없음 | **큼** |
| 절단 | C, 평면·커넥터 | 없음 | 큼 (단, 필요성 낮음) |
| 오브젝트 트리 | 이름변경·눈아이콘·오류표시 | 없음 (파일 목록 수준) | 중간 |
| Undo/Redo | Ctrl+Z/Y + 히스토리 | v2 메인라인에 undo 있음 | 조작과의 연결 확인 필요 |
| 삭제/전체삭제 | Del / Ctrl+Del | 우클릭 삭제 있음 | 단축키·전체삭제 |
| 베드 밖 경고 | 회색 처리 + 슬라이스 차단 | 없음 | 중간 |
| 뷰 단축키 | 0~6, Z, B, Esc | 동일 체계 보유 | 없음 |

## 3. 도입 우선순위 제안 (치과 시나리오: 여러 치아 모델을 플레이트에 놓고 뽑기)

**상 (다음 스프린트급)**
1. **자동 배치(A/Shift+A) + 간격 파라미터** — 치과 워크플로우 핵심(모델 여러 개 올리고 정렬이 매 세션 발생). 난이도 **중**: 치아 모델은 footprint가 단순해 2D 바운딩박스/원 기반 그리드+간격 패킹으로 시작 가능. NFP 같은 정밀 패킹은 후순위.
2. **수치 입력 패널 (Position/Rotation/Scale%/Size mm + 리셋)** — 기즈모는 있으니 양방향 바인딩만 추가. 난이도 **하~중**.
3. **Place on face(F)** — 임포트 방향 교정 최빈 작업. 난이도 **중**: Babylon 픽킹으로 면 법선 취득 → 법선을 아래 방향으로 정렬하는 쿼터니언 계산. 프루사식 "평탄면 후보 하이라이트"는 법선 클러스터링 필요 +α — 1단계는 "클릭한 삼각형 면 기준 정렬"로 축소 가능.

**중**
4. **Delete/Del·Ctrl+Del(전체 삭제)·Ctrl+C/V 단축키 정비** — 기존 컨텍스트 메뉴 기능에 키만 연결. 난이도 **하**.
5. **베드 밖 경고 (회색/빨강 표시 + 슬라이스 차단)** — 출력 실패 예방. 난이도 **하~중**: 바운딩박스 vs 플레이트 AABB 검사.
6. **오브젝트 목록 패널 (이름변경·표시/숨김·선택 연동)** — 모델 수가 늘면 필수. 난이도 **중**: UI 작업 위주.
7. **스냅 증분 (Shift=1mm/5°/5%)** — Babylon 기즈모 snapDistance 속성 활용. 난이도 **하**.

**하 (보류 권장)**
8. **인스턴스 개념** — 프루사에선 FDM 설정 공유+메모리 절약이 핵심인데, 우리는 오브젝트별 설정이 아직 없어 이점이 작음. 데이터 모델(IndexedDB) 변경이 커서 후순위. 당장은 "복제 + 자동 배치" 조합으로 대체. *단 "Fill bed with copies"(복제+배치 일괄) 버튼은 인스턴스 없이도 가능하고 치과 가치 높음 — 자동 배치 완성 후 소품으로 추가 추천.*
9. **절단(Cut)** — 치과 모델은 CAD에서 완성돼 옴. 난이도 **상**(메시 불리언/캡핑) 대비 효용 낮음.

## 4. UI 배치 제안 (좌측 세로 툴바 도입 시)

프루사의 "상단=장면 관리 / 좌측=오브젝트 변형 모드" 이원화를 따르되, 우리 규모에 맞게 축소:

**좌측 세로 툴바 (위→아래, 배타적 모드 툴, 선택 시 활성화)**
1. 이동 (M)
2. 크기 (S)
3. 회전 (R)
4. 바닥면 지정 (F)
- 배열 근거: 프루사와 동일한 빈도순 + 사용자가 다른 슬라이서(CHITUBOX도 유사)에서 익힌 멘탈모델 유지. Cut·페인팅류는 도입 전까지 아이콘 자체를 두지 않음(비활성 아이콘 나열 금지).

**상단(또는 기존 툴바)에 추가**: 자동 배치(A) — 우클릭/드롭다운으로 간격(mm)·회전 허용 설정, 전체 삭제, Undo/Redo.
**우측 패널**: 선택 시 수치 입력 패널(Position/Rotate/Scale%/Size mm) + 그 위에 오브젝트 목록 트리. 기존 우클릭 컨텍스트 메뉴(삭제/복제/줌투핏) 유지, 복제 옆 "복제 후 배치" 항목 추가 검토.

## 5. 주의사항 (AGPL)

- PrusaSlicer는 **AGPL-3.0**. 본 조사는 공식 문서·매뉴얼·서드파티 가이드만 참고, 소스 코드 미열람 (클린룸 유지). 구현 시에도 **prusa3d/PrusaSlicer 저장소 코드 열람·참조 금지**, DeepWiki 등 코드 파생 요약도 회피.
- **아이콘 SVG 등 에셋 복사 금지** — 자체 제작 또는 MIT/Apache 아이콘셋(lucide, heroicons) 사용.
- 단축키 체계(M/R/S/F/A 등)·UI 배치 같은 "개념·관례"는 저작권 대상이 아니므로 채택 가능.
