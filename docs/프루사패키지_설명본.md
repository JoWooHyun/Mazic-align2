## 패키지 A — 출력 품질 (안티앨리어싱 + 코끼리발 보정) · 개발 약 1주

### A-1. 안티앨리어싱 (Anti-aliasing)
**뭐냐**: 마스크 이미지의 경계(모델 테두리)를 흑/백 계단이 아니라 회색 단계로 부드럽게 만드는 것. LED가 경계 픽셀을 "반쯤" 경화시켜 표면 결이 매끈해집니다.
**왜 우리에게**: 보철물 표면 품질 — 특히 곡면(치아 형태)에서 층 결이 눈에 띄게 줄어듭니다.
**PrusaSlicer에서 눌러보기**: SL1S 선택 상태에서 아무 모델이나 슬라이스 → 좌하단 미리보기에서 레이어를 확대해 경계가 부드러운 회색 그라데이션인 것 확인. (프린터 설정 → 일반에 안티앨리어싱 관련 항목)
**우리가 만들면**: 마스크 생성 마지막 단계에 경계 픽셀 회색 처리 추가. 기존 파이프라인에 얹기만 — 켜고 끄기 옵션 제공.

### A-2. 코끼리발 보정 (Elephant foot compensation)
**뭐냐**: 첫 몇 층이 과경화로 옆으로 퍼지는 현상(코끼리 발처럼)을, 첫 층 마스크를 살짝 안쪽으로 깎아서 상쇄하는 것.
**왜 우리에게**: 바닥에 닿는 면의 치수 정확도 — 모델베이스 아랫면이 부풀지 않게.
**PrusaSlicer에서 눌러보기**: 출력 설정(Print Settings) → 보정(Corrections) 항목에서 값(mm)을 넣고 슬라이스 → 첫 레이어 미리보기가 살짝 작아진 것 확인.
**우리가 만들면**: 첫 N층 마스크를 설정값만큼 침식(erode). 프로파일에 보정값 필드 추가.

## 패키지 B — 재료 절약 (홀로잉 + 드레인 홀) · 개발 약 1개월

### B-1. 홀로잉 (Hollowing, 속 비우기)
**뭐냐**: 꽉 찬 모델의 속을 지정 두께(예: 벽 2mm)만 남기고 비우는 것.
**왜 우리에게**: **레진값 직결** — 모델베이스처럼 덩어리가 큰 출력물에서 재료 소모가 크게 줄고, 무게도 가벼워집니다.
**PrusaSlicer에서 눌러보기**: SLA 모드에서 모델 선택 → 우측 툴바의 **속 비우기(Hollow) 도구** → 벽 두께 설정 → 슬라이스 후 중간 레이어를 보면 도넛 모양(테두리만)인 것 확인.
**우리가 만들면**: 유승제 CSG(manifold) 자산으로 내부 오프셋 mesh를 만들어 빼기. 두께 설정 UI 포함.

### B-2. 드레인 홀 (Drain holes, 배출 구멍)
**뭐냐**: 속을 비우면 안에 미경화 레진이 갇히므로, 빠져나올 구멍을 뚫는 것 (안 뚫으면 압력/세척 문제).
**PrusaSlicer에서 눌러보기**: 홀로잉 도구 안에서 구멍 추가 → 모델 표면 클릭으로 배치.
**우리가 만들면**: 표면 클릭으로 원통 빼기(CSG). 홀로잉과 세트.

## 패키지 C — 작업 편의 (자동 배치 + 자동 방향) · 개발 약 2주

### C-1. 자동 배치 (Arrange)
**뭐냐**: 모델 여러 개를 플레이트 위에 겹치지 않게 자동 정렬.
**왜 우리에게**: 보철 여러 개 동시 출력 시 손 배치 시간 절약.
**PrusaSlicer에서 눌러보기**: 모델 3~4개 불러오기 → 상단 툴바 **배치(Arrange, A키)** → 자동 정렬 확인.
**우리가 만들면**: 2D footprint 패킹. 버튼 하나.

### C-2. 자동 방향 (Auto-orientation)
**뭐냐**: 서포트가 최소가 되는 기울기를 자동으로 찾아 회전.
**왜 우리에게**: 지현규님이 만들다 비활성화한 기능(autoAngle)의 완성형 — 오버행 검출 자산 재활용.
**PrusaSlicer에서 눌러보기**: 모델 우클릭 또는 툴바에서 방향 최적화 실행 → 모델이 기울어지고 서포트 수 변화 확인.
**우리가 만들면**: 후보 각도들을 오버행 면적으로 채점해 최소 선택. (지현규 컨펌 항목)

## 개별 검토 (패키지 밖 — 참고로 눌러보기)

- **가변 레이어 (Variable layer height)**: 곡면 구간만 얇게 → 품질·시간 균형. FDM 모드 툴바에서 체험 가능.
- **컷 툴 (Cut)**: 모델 평면 자르기 — 툴바 C키.
- **메시 수리**: 깨진 STL 자동 수선 — 파일 메뉴. (우리 쪽 구현은 장기 과제)
