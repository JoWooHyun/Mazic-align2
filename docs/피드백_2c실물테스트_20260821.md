## 2c-f (재작업) 범위 — 2d보다 우선

1. **T-2**: 충돌 검사 백엔드를 Babylon 레이캐스트에서 **자체 순수 삼각형 인덱스**(균일 그리드,
   `extractWorldTriangles`+감김 정규화 입력)로 교체. 효과 3중 — 성능(브루트포스 제거),
   감김 신뢰(B-7 정규화 관문 공유), **검수 사각지대 ①(프로브 실동작) 헤드리스 검증 가능화**.
2. **T-1**: 내부 재발사 허용치를 옵션화하고 기본값을 화살촉 침투 기준(≈0.4mm)으로 축소.
3. **T-3**: `maxMembersPerPillar` 옵션 도입(기본 유한값) — 초과 멤버는 다음 라운드로 반환해
   클러스터 자연 분할. ※ 기둥 수는 지금보다 **늘어난다**(물리적으로 타당한 방향).
4. 검증: 파묻힘>허용치 차단·평행 스침·상한 분할·성능 스모크(대형 삼각형×대량 광선 시간 상한)
   + 기존 대조군 규약.
