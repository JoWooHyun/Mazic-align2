      실제 패널은 재계산하지 않았다 — **스크립트가 배선보다 관대한 조건을 테스트**했다.
      (e) "고정 오프셋 = 패널 실동작" 케이스 추가로 해소. B-1의 대조군 규약과 같은 교훈.

      회전 후 POSITION Y가 CHITUBOX처럼 0이 되지 않는 건(우리는 모델높이/2) CHITUBOX의

      `updateGizmoRotationToMatchAttachedMesh=false`가 v2 이관 때 누락(Babylon 기본값 true=local).
