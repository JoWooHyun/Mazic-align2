[1] 프로젝트 개요
--------------------------------------------------------------------------------

  MazicAlign은 Top-down 레진 프린터용 슬라이서이다.

  최종 목표: 2개 노즐로 레진을 FDM 방식처럼 경로 도포하는 하이브리드 프린터 지원
  현재 단계: 일반 레진 프린터 슬라이서로서의 최소 완결 워크플로우 구축

  현재 상태:
    [O] STL 파일 로드 및 3D 뷰어 (Babylon.js)
    [O] Transform 컨트롤 (이동/회전/크기 + Gizmo)
    [O] Z축 레이어 슬라이싱 (Web Worker)
    [O] FDM G-code 생성 (벽/인필/이동)
    [O] DLP 마스크 이미지 생성 (PNG)
    [O] 2D 레이어 프리뷰
    [O] 프로파일 저장/불러오기 (localStorage)
    [X] 바닥 레이어 / 전환 레이어 처리
    [X] 리프트 / 라이트오프 딜레이 설정
    [X] 파일 내보내기 (G-code + 이미지)
    [X] 빌드 플레이트 시각화
    [X] 드래그앤드롭 파일 열기
    [X] 서포트 UI


[2] 이번 작업 범위
--------------------------------------------------------------------------------

  ── 포함 ──
    1. DLP 설정 강화 (CHITUBOX 수준의 파라미터)
    2. 빌드 플레이트 + 그리드 시각화
    3. 드래그앤드롭 파일 열기
    4. 슬라이스 결과 내보내기 (ZIP: 레이어 이미지 + G-code + 메타데이터)
    5. 서포트 UI (껍데기만, 실제 로직은 나중에)
    6. FDM G-code 기본 개선 (헤더/푸터, 온도, 리트랙션 - 하이브리드 대비)

  ── 신규 의존성 ──
    - jszip : ZIP 파일 생성 (내보내기용)

  ── 제외 ──
    - 프린터 프로파일 시스템 (기종별 설정 관리)
    - 서포트 자동 생성 로직
    - .ctb / .cbddlp 등 프린터별 바이너리 포맷
    - 안티앨리어싱

[4] 상세 구현 계획
================================================================================


  Step 1: types.ts - DLP 설정 확장 + SlicerResult
  --------------------------------------------------------------------------

    (A) SliceSettings 인터페이스 - DLP 신규 필드 추가

      필드명                    | 타입     | 기본값  | 설명
      --------------------------|----------|---------|---------------------------
      bottomExposureTime        | number   | 30      | 바닥 레이어 조사 시간 (초)
      bottomLayerCount          | number   | 6       | 바닥 레이어 수
      transitionLayerCount      | number   | 6       | 전환 레이어 수 (점진 변환)
      liftDistance              | number   | 6.0     | Z축 리프트 거리 (mm)
      liftSpeed                 | number   | 3.0     | Z축 상승 속도 (mm/s)
      retractSpeed              | number   | 3.0     | Z축 하강 속도 (mm/s)
      lightOffDelay             | number   | 1.0     | 조사 후 대기 시간 (초)

      ※ 기존 optional 필드 (bottomExposure?, bottomLayers?, liftDistance?,
         retractSpeed?) 제거 → 위의 required 필드로 대체

    (B) SliceSettings 인터페이스 - FDM 신규 필드 추가

      필드명                    | 타입     | 기본값  | 설명
      --------------------------|----------|---------|---------------------------
      nozzleTemp                | number   | 200     | 노즐 온도 (℃)
      bedTemp                   | number   | 60      | 베드 온도 (℃)
      enableRetraction          | boolean  | true    | 리트랙션 활성화
      retractLength             | number   | 5.0     | 리트랙션 거리 (mm)
      retractZHop               | number   | 0.2     | Z-hop 높이 (mm)
      retractMinTravelDistance   | number   | 1.0     | 리트랙션 최소 이동거리 (mm)
      fanSpeed                  | number   | 100     | 팬 속도 (%)
      fanDisableLayerCount      | number   | 2       | 팬 비활성 첫 N개 레이어

    (C) 신규 타입 추가

      SlicerResult {
        layers: LayerData[]        // 레이어별 데이터
        fullGcode: string          // FDM 전체 G-code
        metadata: SliceMetadata    // DLP 메타데이터
      }

      SliceMetadata {
        totalLayers, layerHeight, buildWidth, buildDepth, buildHeight,
        resolutionX, resolutionY, exposureTime, bottomExposureTime,
        bottomLayerCount, estimatedTime (예상 출력 시간, 초)
      }

    (D) LayerData 확장
      - exposureTime: number 필드 추가 (레이어별 실제 조사 시간)


  Step 2: SlicerPanel.tsx - DLP 탭 UI 대폭 확장
  --------------------------------------------------------------------------

    CHITUBOX의 "출력" 설정 탭을 참고하여 DLP 탭 재구성:

    ┌─────────────────────────────────────────┐
    │  ─── Display ───                        │
    │  Resolution X:          [3840]          │
    │  Resolution Y:          [2400]          │
    │  Pixel Size:            [50] μm (auto)  │
    │                                         │
    │  ─── Exposure ───                       │
    │  Normal Exposure Time:  [2.5] s         │
    │  Bottom Exposure Time:  [30] s          │
    │  Bottom Layer Count:    [6]             │
    │  Transition Layers:     [6]             │
    │  Light Power:           [80] %          │
    │  Light-Off Delay:       [1.0] s         │
    │                                         │
    │  ─── Z Movement ───                     │
    │  Layer Height:          [0.05] mm       │
    │  Lift Distance:         [6.0] mm        │
    │  Lift Speed:            [3.0] mm/s      │
    │  Retract Speed:         [3.0] mm/s      │
    └─────────────────────────────────────────┘

    ※ 레이어 높이 기본값: 0.1mm → 0.05mm (레진 프린터 기본)
    ※ pixelSize 자동 계산 유지: buildWidth / resolutionX * 1000


  Step 3: ImageGenerator.ts - 해상도 동적 적용
  --------------------------------------------------------------------------

    변경 전: 해상도 1920x1080 하드코딩
    변경 후: settings.resolutionX, resolutionY, pixelSize에서 동적 계산

    pixelPerMm = 1000 / settings.pixelSize
    → ImageGenerator.generateLayer(polygons, resolutionX, resolutionY, pixelPerMm)


  Step 4: SlicerWorker.ts - 바닥/전환 레이어 + 결과 조립
  --------------------------------------------------------------------------

    (A) 레이어별 조사 시간 계산
      - 바닥 레이어 (i < bottomLayerCount): bottomExposureTime 적용
      - 전환 레이어: 선형 보간 (바닥 → 일반 조사시간 점진 전환)
      - 일반 레이어: exposureTime 적용

    (B) 예상 출력 시간 계산
      각 레이어: 조사시간 + 라이트오프 딜레이
                + (리프트 거리 / 상승 속도)
                + (리프트 거리 / 하강 속도)

    (C) FDM 전체 G-code 조립
      헤더 + 레이어별 G-code + 푸터

    (D) SlicerResult 형태로 반환
      { layers, fullGcode, metadata }


  Step 5: GCodeGenerator.ts - FDM 기본 개선
  --------------------------------------------------------------------------

    (A) generateHeader() 메서드 추가
      - G90 (절대좌표), M82 (절대 압출), G28 (홈)
      - M104/M109 (노즐 온도), M140/M190 (베드 온도)
      - G92 E0 (압출 리셋), M107 (팬 끄기)

    (B) generateFooter() 메서드 추가
      - 리트랙트, Z 올리기, XY 홈
      - M104 S0, M140 S0 (온도 끄기), M107 (팬 끄기), M84 (모터 비활성)

    (C) 리트랙션 로직
      - travel 거리 > retractMinTravelDistance일 때:
        → G1 E-{length} (리트랙트) + G0 Z+{zhop} (Z-hop)
        → 다음 압출 전: G0 Z{layer_z} (복귀) + G1 E+{length} (언리트랙트)

    (D) 팬 제어
      - fanDisableLayerCount 번째 레이어에서 M106 S{pwm} 팬 켜기


  Step 6: SlicerService.ts - 반환 타입 변경
  --------------------------------------------------------------------------

    Promise<LayerData[]> → Promise<SlicerResult> 로 변경
    내부 로직 동일, 타입만 변경


  Step 7: babylon.utils.ts - 빌드 플레이트 시각화
  --------------------------------------------------------------------------

    createBuildPlate(scene, width, depth, height) 함수 추가:

      1. 바닥판: MeshBuilder.CreateGround (반투명, alpha 0.3)
      2. 그리드: MeshBuilder.CreateLineSystem (10mm 간격, 회색)
      3. 볼륨 경계: 12개 edge 와이어프레임 박스 (파란색, alpha 0.6)

      ※ 모든 mesh는 isPickable = false

    disposeBuildPlate(meshes) 함수 추가


  Step 8: STLViewer.tsx - 빌드 플레이트 연동
  --------------------------------------------------------------------------

    - buildPlateConfig prop 추가: { width, depth, height }
    - 초기화 시 createBuildPlate() 호출
    - config 변경 시 dispose → 재생성


  Step 9: ViewerPage.tsx - 전체 통합
  --------------------------------------------------------------------------

    (9-1) 드래그앤드롭 파일 열기
      - 메인 뷰어에 onDragOver / onDragLeave / onDrop 핸들러
      - .stl 파일만 필터, 중복 체크
      - useSTLFiles 훅의 addLocalFile(file) 호출 (blob URL 생성)
      - 드래그 중 시각적 오버레이 ("Drop STL files here")

    (9-2) 내보내기 버튼 (슬라이서 모달)
      - 슬라이서 모달 헤더에 "Export" 버튼

      ZIP 파일 구조:
      ┌──────────────────────────────────────┐
      │  {모델명}_sliced.zip                  │
      │  ├── metadata.json    ← 출력 파라미터 │
      │  ├── print.gcode      ← FDM G-code   │
      │  └── layers/                          │
      │      ├── 0001.png     ← DLP 마스크    │
      │      ├── 0002.png                     │
      │      ├── ...                          │
      │      └── NNNN.png                     │
      └──────────────────────────────────────┘

      - JSZip 라이브러리로 ZIP 생성
      - Data URL → Blob 변환 후 zip에 추가
      - 슬라이싱 안 했으면 버튼 비활성화

    (9-3) 서포트 UI (껍데기)
      - 뷰어 우측 패널에 "서포트" 탭 추가 (변환/히스토리 옆)
      - CHITUBOX 참고한 UI:
        - 상단/중앙/바닥/라프트 서브탭
        - 접점 형태, 직경, 길이 입력 (비활성 상태)
        - "자동 서포트" / "수동 서포트" 버튼 (비활성)
        - "Coming Soon" 표시

    (9-4) 빌드 플레이트 연결
      - localStorage에서 빌드 치수 읽어 STLViewer에 전달

    (9-5) 슬라이스 결과 처리

      - 예상 출력 시간 표시 (모달에 "예상 시간: X분 Y초")

[6] 검증 방법
--------------------------------------------------------------------------------

    1. npm run dev 로 프론트엔드 실행
    2. STL 파일 드래그앤드롭 → 로드 확인 + 빌드 플레이트 위에 모델 표시
    3. 슬라이서 열기 → DLP 탭에서 바닥 노출, 전환 레이어, 리프트,
       라이트오프 설정 입력 확인
    4. 슬라이싱 실행 → 2D 프리뷰에서 레이어 탐색
       → 바닥 레이어와 일반 레이어의 exposureTime 차이 확인
    5. 예상 출력 시간 표시 확인
    6. Export 클릭 → ZIP 파일 다운로드
       → 압축 해제하여 metadata.json, print.gcode, layers/*.png 확인
    7. 서포트 탭 → UI 표시 확인 (비활성 상태)
