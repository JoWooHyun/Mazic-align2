## B. 발견 문제 — 분류와 1차 원인

### B-1. 생성 후 모델 이동/회전 시 서포트가 따라가며 기울어짐 (심각·설계 판단 필요)

- 현상: STL을 회전/이동하면 서포트가 같이 움직여 기둥이 기울고 공중에 뜸. 화살표(기즈모) 드래그 시 갑자기 점프.
- 원인: `useSupportMeshSync`가 `mesh.parent = stlMesh`로 STL transform을 자동 추종(stl-local 저장).
  PR #39 알려진 한계("저장 후 모델 이동 시 재생성 필요")의 실물 확인.
- 필요 결정: 모델 transform 시 재설계 서포트 처리 정책 — CHITUBOX식 "무효화(경고+삭제)" vs 자동 재생성.

### B-2. 일정 시간 뒤 서포트가 움직이거나 다시 생성됨 (버그 의심·진단 필요)

- 현상: 어떤 메커니즘에 의해 잠시 후 서포트가 이동하거나 재생성됨.
- 1차 추정: `useSupportMeshSync`의 rebuild key가 "STL local 좌표+params" 기준인데,
  stl-local이 아닌 점(구 좌표계 점)은 매 실행마다 inv(world) 변환값으로 key가 바뀌어
  STL 이동 후 effect 재실행 시 재생성될 수 있음. headless/뷰어 재현으로 확정 필요.

### B-3. 재설계 서포트가 과다 생성 (약 1,300개) (기본값·검출 문제)

- 원인 후보 2가지(중첩):
  1. 오버행 검출이 검출각 미적용 층-겹침 근사(S-4a 알려진 TODO) → 과검출.
  2. 점 간격 기본값 `fillSpacingMm=3.0` / `overhangSpacingMm=3.0` 고정
     (`support/utils/defaults.ts`) — 조절 UI는 S-4d 예정이라 현재 사용자가 못 바꿈.
- 영향: 출력물 품질 + S-4b-2 충돌회피(기둥당 광선 8~16개)가 1,300개면 연산 폭발.
  **S-4b-2 착수 전 완화 권장.**

### B-4. 재설계 디버그 표시(마젠타/파랑/주황 점)가 모델을 안 따라가고 잔류

- 원인: 디버그 오버레이는 world 좌표로 직접 찍고 parent 없음(`redesign-detect-actions.ts`).
- "표시 지우기"로 제거되는 것은 정상. 생성 시 자동 정리 여부는 기존 보류 항목 — 이번에 정리 권장.

### B-7. 서포트·모델 겹침 영역이 마스크에서 검은색(구멍) — **✅ 수정 완료, PR #40 머지 대기** (2026-08-11)

- **처리(2026-08-11)**: dev-cycle로 수정 완료, 검수 1차 PASS → **PR #40** (`fix/v2-raster-union-b7`,
  d3ab557). even-odd → nonzero 감김 전환 + 헤드리스 검증 6케이스. 머지 = 리드.

- 현상(리드): ZIP 마스크에서 서포트가 모델을 관통한 층의 겹침 부위가 **검은색** = 미경화 → 출력물에 구멍.
- 원인 확정: `utils/slice-rasterize.ts`의 scanline이 **모든 폴리곤을 한꺼번에 even-odd 규칙**으로 채움.
  주석은 "여러 polygon 의 union 자동 처리"라고 주장하나 실제로는 **서로 다른 물체가 겹치면 XOR로 취소**되어
  겹침 = 구멍이 된다. even-odd는 한 물체의 외곽+내부구멍에만 유효.
- 영향 범위 (관통 기둥만의 문제가 아님):
  1. 화살촉 팁은 **의도적으로 0.2mm 침투**(설계 4-1) → S-4b-2로 관통을 없애도 **모든 접점 층에 미세 구멍**.
  2. S-4b-1 재작업이 발↔기둥·부품 간 **의도적 겹침 조립**을 함 → 서포트 자체 단면에도 취소 영역 가능.
  3. 두 STL 모델을 겹쳐 배치해도 동일 → v2 래스터화 도입 이래 잠복.
  4. ZIP PNG·CTB·슬라이스 프리뷰가 같은 마스크 사용 → 실기 출력물에 그대로 반영.
- 수정 방향: 물체(메시) 단위 래스터 후 비트 OR 합성, 또는 clipper union 선행, 또는 일관 감김방향+nonzero.
  겹침·침투가 전제인 B안 조립과 공존하려면 필수 — **S-4b-2보다 먼저 수정해야 함.**

### B-8. (B-7 검수 중 발견) FDM G-code 경로에 동종 버그 잔존 — 후속

- `utils/gcode/polygon-clipper.ts:67`의 union이 `pftEvenOdd` — FDM 레이어에서 겹친 메시(모델+서포트)의
  겹침이 XOR로 지워질 수 있음. B-7 수정으로 감김이 신뢰 가능해졌으므로 `pftNonZero` 전환 검토 가치.
  DLP 주력이라 시급하지 않음 — 트랙 B 또는 G-code 손볼 때 함께. (B-7 reviewer 발견 2026-08-11)
