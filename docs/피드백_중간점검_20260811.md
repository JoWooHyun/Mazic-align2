### B-7. 서포트·모델 겹침 영역이 마스크에서 검은색(구멍) — **✅ 완료: PR #40 머지 (68bb5e7, 2026-08-11)** (사후 실물 확인 권장 — 아래)

- **처리(2026-08-11)**: dev-cycle로 수정 완료, 검수 1차 PASS → **PR #40** (`fix/v2-raster-union-b7`,
  d3ab557). even-odd → nonzero 감김 전환 + 헤드리스 검증 6케이스. 머지 = 리드.
- **리드 실물 확인 FAIL 1건 → 재작업(9498b46, 재검수 PASS)**: 재설계 서포트·모델 겹침 부위에
  초승달 구멍 잔존. 원인 = **Babylon STL 로더의 기본 Y/Z 스왑(반사)** 으로 모델 감김이 데이터상
  뒤집혀(−1), 정상 감김(+1)인 재설계 조립 서포트와 겹침만 상쇄. 구 trunk(Babylon 도형)는 모델과
  같은 관례라 정상 — "기본 서포트는 안 그런다"는 리드 관찰이 원인 특정의 결정적 단서였음.
  수정 = `extractWorldTriangles`(전 슬라이스 경로 단일 관문)에서 부호 부피 기반 감김 자동 정규화
  (`normalizeTriangleWinding`). 혼합 감김 회귀 (g) 3항목 추가. 교훈: 자동 검증이 정상 감김 입력만
  써서 못 잡음 — 실물 확인의 가치 입증.

- 현상(리드): ZIP 마스크에서 서포트가 모델을 관통한 층의 겹침 부위가 **검은색** = 미경화 → 출력물에 구멍.
- 원인 확정: `utils/slice-rasterize.ts`의 scanline이 **모든 폴리곤을 한꺼번에 even-odd 규칙**으로 채움.
  주석은 "여러 polygon 의 union 자동 처리"라고 주장하나 실제로는 **서로 다른 물체가 겹치면 XOR로 취소**되어
  겹침 = 구멍이 된다. even-odd는 한 물체의 외곽+내부구멍에만 유효.
- 영향 범위 (관통 기둥만의 문제가 아님):
  1. 화살촉 팁은 **의도적으로 0.2mm 침투**(설계 4-1) → S-4b-2로 관통을 없애도 **모든 접점 층에 미세 구멍**.
  2. S-4b-1 재작업이 발↔기둥·부품 간 **의도적 겹침 조립**을 함 → 서포트 자체 단면에도 취소 영역 가능.
  3. 두 STL 모델을 겹쳐 배치해도 동일 → v2 래스터화 도입 이래 잠복.
  4. ZIP PNG·CTB·슬라이스 프리뷰가 같은 마스크 사용 → 실기 출력물에 그대로 반영.
- 수정 방향: 물체(메시) 단위 래스터 후 비트 OR 합성, 또는 clipper union 선행, 또는 일관 감김방향+nonzero.
  겹침·침투가 전제인 B안 조립과 공존하려면 필수 — **S-4b-2보다 먼저 수정해야 함.**

### B-8. (B-7 검수 중 발견) FDM G-code 경로에 동종 버그 잔존 — 후속

  DLP 주력이라 시급하지 않음 — 트랙 B 또는 G-code 손볼 때 함께. (B-7 reviewer 발견 2026-08-11)

### B-9. 회전 피벗이 모델을 벗어남 — 회전이 공전처럼 보임 (2026-08-11 리드 추가 제기, 원인 특정)

- 현상: 회전 기즈모 고리가 모델 밖 허공에 떠 있고, 회전시키면 모델이 그 점을 중심으로
  공전(좌표 이동)하는 것처럼 보임.
- 원인 (코드 특정): 메시 원점(피벗)이 **로드 시점의 "바닥 중심"에 정점 베이크로 박제**됨
  (`stl-loader.ts` alignMeshToPlate). 기즈모·수치패널·바닥면 붙이기는 전부 이 원점 기준
  회전(quaternion)이라 — ①부피 중심이 아닌 바닥 중심이라 키 큰 모델은 X/Z 회전 시 스윙
  ②한 번이라도 회전하면(기즈모/바닥면 붙이기) 모델 실루엣이 원점에서 벗어나 이후 회전은
  공전처럼 보임. `computeAlignFloorTransform`도 회전만 바꾸고 XZ 위치 보정 없음.
- 비교: CHITUBOX·프루사는 회전·스케일 피벗을 **현재 바운딩박스 중심**으로 매번 재계산.
- 수정 방향(제안): 기즈모를 현재 world bbox 중심의 프록시 노드에 부착하고 드래그 델타를
  "bbox 중심 기준 회전 + position 보정"으로 환산 (TransformV2 데이터 모델·stl-local 서포트
  비파괴). 수치패널·바닥면 붙이기도 같은 피벗 유틸 경유. 중형 작업 — 착수는 리드 지시.

### B-10. (참고) G-code 팅김/멈춤 — 원인 실측 완료, 우선순위 보류 (리드 결정 2026-08-11)

  인덱싱 없음 — DLP ZIP/CTB 경로 공통, 예전 "대형 19.7분"의 원인이기도).
