## 6. 사용법 — 새 컴퓨터에서 (터미널 없이, 더블클릭만)

### 준비물 (한 번만)
1. **Node.js 설치**: 브라우저로 https://nodejs.org 접속 → 초록색 **LTS** 버튼 클릭해 다운로드
   → 받은 파일 더블클릭 → 설치 마법사에서 계속 "다음"만 클릭 (설정 바꿀 것 없음)

### 프로그램 받기
2. 브라우저로 **https://github.com/JoWooHyun/Mazic-align2** 접속 (팀원 계정 로그인)
3. 초록색 **`<> Code`** 버튼 클릭 → **Download ZIP** 클릭
4. 받은 ZIP 파일 우클릭 → **"압축 풀기"** → 원하는 폴더에 풀기 (예: 바탕화면)

### 실행
5. 풀린 폴더를 열고 **`start-dev.bat` 더블클릭** — 이게 전부입니다.
   - 처음엔 필요한 것들을 자동으로 설치하느라 몇 분 걸립니다 (검은 창에 글자가 올라가는 게 정상)
   - 끝나면 **브라우저가 자동으로 열리며** 앱이 나타납니다 (주소: localhost:5173/v2)
6. 사용: 프로젝트 만들기 → "내 PC에서 열기"로 STL 불러오기 (또는 파일을 화면에 드래그)
   → Dental 모드에서 브러쉬/마진/아일랜드 → 서포트 → 슬라이스 → 내보내기

### 종료 / 그 외
- **끄기**: 검은 창을 닫거나 `stop-dev.bat` 더블클릭
- **다음부터는** `start-dev.bat` 더블클릭만 (설치 단계 자동 생략)
- 같은 네트워크의 다른 기기에서 보려면: 검은 창에 표시되는 `http://192.168.x.x:5173/v2` 주소로 접속
- 문제가 생기면: 창을 전부 닫고 `start-dev.bat` 다시 더블클릭 → 그래도 안 되면 검은 창의 빨간 글씨를 캡처해서 공유
- ⚠️ ZIP으로 받은 폴더는 그 시점의 스냅샷입니다. **최신으로 갱신하려면 ZIP을 새로 받아서 다시 풀면 됩니다** (작업물은 브라우저에 저장되므로 폴더를 지워도 프로젝트는 남습니다 — 단, 같은 컴퓨터·같은 브라우저 기준)
