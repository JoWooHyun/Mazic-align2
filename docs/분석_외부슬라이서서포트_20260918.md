| 저장소 | 언어 | 라이선스 | 최근 커밋 | 서포트 코드 규모 |

## 1. mslicer (Rust, GPL-3)

README가 스스로 "서포트는 매우 초기, 권장 방법은 외부 도구 Runebrace"라고 명시. 자동 생성은 실험 수준.

### 검출 — 메시 기반 3종
- **면(face)**: 법선 각도 `acos(-n.z) <= max_angle(30°)`로 오버행 면 선정. 그 면 위에 **준난수(quasirandom, 플라스틱 상수 R2 수열)** 2D 점을 베드 전체에 뿌리고 +Z 레이로 면과 교차하는 점만 채택. (격자 대신 R2 수열 → 규칙적 패턴 없이 고른 분포)
- **엣지(edge)**: 오버행 면과 이웃 면의 법선 차가 `edge_angle_delta(0.1rad)` 이상인 엣지를 union-find로 런(run)으로 묶고, 런을 따라 `edge_support_spacing(20mm)` 간격 샘플.
- **점(point)**: 아래 향한 법선이면서 **이웃 정점보다 전부 낮은 정점**(국소 최저점).
- 우선순위 점 > 엣지 > 면. `min_spacing(5mm)` 이내 중복은 O(n²)로 제거.

### 라우팅 — 모멘텀 그래디언트 하강
```
tip_start = 접점 + 법선 × tip_length
100회 반복: BVH 최근접점으로부터 멀어지는 방향(grad)을 momentum(β=0.9)으로 누적,
            z 성분은 음수만 허용(위로는 못 감), 최근접 거리(≤1mm)만큼 전진
            → 아래로 레이 쏴서 안 맞으면 그 점이 mid, 거기서 수직 낙하
실패 시 None → 그 접점은 버림
```
즉 "모델 표면에서 밀려나며 미끄러져 내려오는" 경로. 각도 제한 없음(notes.md에 "덜 가파른 각도 원함" TODO).

### 형상
- 3점 `[접점, tip_start, mid]` + mid 수직투영. 실린더 3개(팁 원뿔 0.2→1.0, 기둥, 수직) + 구 3개.
- 라프트: 모든 기둥 발 주위 점의 **convex hull**을 offset/height로 경사 슬래브.
- 브레이스/좌굴 방지: **없음**.

### 참고할 점 / 한계
- R2 준난수 면 샘플링은 격자 모아레 없이 균일 — 우리 `fillSpacingMm` 격자 대안 개념.
- 라우팅이 각도 무제한·수렴 보장 없음, 서포트끼리 충돌 검사 없음, 저장/편집 미완.

## 2. Resin-Slicer (Python, MIT)

### 파이프라인 — **메시 없이 래스터 스탬프**
서포트 메시를 만들지 않는다. `plan_supports`가 앵커 리스트를 만들고, 층별로 `apply_supports`가 **원반(disk)을 슬라이스 래스터에 직접 OR** 한다. 분석은 `analysis_max_pixels(250k)`로 다운스케일된 해상도에서 수행(11520×5120 프린터면 면적 236배 축소).

### 검출 — 층간 팽창 차분 (우리 층 그래프와 같은 계열)
```
allowance_px = floor((layer_h × gap_layers / tan(angle) + margin) / pixel_mm)
support_mask = dilate(아래층, allowance_px)
unsupported  = 현재층 − support_mask → connected components(min_area 0.08mm²)
```
- **lookback**: 층높이가 작아 한 층 차분이 1px 미만이면 `ceil(pixel_mm / allowance_per_layer)` 층(최대 24) 아래를 기준면으로. deque로 히스토리 유지. → 미세 층높이에서 검출 붕괴 방지. **우리 layer-graph의 `overlapSampleMm`·지지반경 판정에 같은 문제 가능성 확인 필요.**
- 아일랜드당 점: 중심 1 + `support_spacing(3mm)` 격자 버킷의 "첫 픽셀"(BFS 순 → 가장자리로 치우침, 결함).
- 법선은 검출이 아니라 **팁 방향**에만 사용(공간 해시로 근접 삼각형 30개 평균, `dot>0.95` 정렬 필터로 인접 수직벽 오염 배제).

### 라우팅 — 기둥은 항상 수직, 팁만 기울임
- `base.xy == joint.xy` 불변식(테스트로 고정). 팁(0.8mm)만 법선 방향, 최대 약 19° 기울기.
- 충돌: 층별 원반 검사(`bytearray.find(255)` C 스캔). 실패 시 **옆으로 비켜가는 탐색 없음** → `enforcers_enabled`(기본 off)면 같은 XY 아래 모델 살에 착지(model-to-model, 1~10mm), 아니면 조용히 폐기.
- 브랜치/트리 병합 없음.

### 형상 (층별 반경 프로파일)
- 기둥 r=0.28 상수(테이퍼 없음) → 팁 구간 0.8mm에서 0.18로 선형(cone) / sphere(sin(πt) 벌브) / cylinder.
- 조인트 구(꺾임부 메움), 선택적 구형 접촉(법선 방향으로 `radius−inset` 밀어넣은 구).
- 베드: none / feet / raft(모델 XY 그림자 투영 + 0.6mm 팽창) / skate. 라프트 **챔퍼가 바닥이 좁고 위가 넓은 역테이퍼**(이형 용이).

### 브레이스 — 있음
- bed 앵커(base_layer 0)만 대상, 최근접 2개와 45° 대각 연결(`brace_max_distance 8mm`).
- `brace_interval`>0이면 높이마다 반복하되 **레벨마다 방향 반전 → 지그재그 트러스**.
- 45°가 안 들어가면 시작층을 낮추고 각도를 눕히되 **18°(45°의 1/3) 미만이면 포기** — 래스터 디스크 스택의 층간 연결 끊김 한계를 각도 하한으로 인코딩.
- 브레이스도 모델 충돌 검사. 기둥 높이·세장비 미고려(고립 기둥은 브레이스 0).

### 결함/데드 코드
- `max_support_angle_deg`, `max_base_reach_mm`, `raft_layers` — UI/검증에 노출되나 **미사용**. 관련 테스트는 항상 통과(각도가 구조상 0).
- 라우팅 실패 무경고, 다운스케일 충돌검사와 출력 해상도 불일치(`collision_clearance 0.08mm`가 분석 픽셀보다 작아 무의미), 테스트는 저해상도 프로파일에서만.

## 3. VoxelMill (Python, MIT) — 가장 완성도 높음

### 파이프라인 — 메시 + 자체 래스터 "컬럼 필드" 이중 증거
- `build_column_field`: 배치 모델을 0.15mm(하한 프린터 피치) 격자로 층별 래스터화 → **컬럼별 material run `[lo,hi)`를 CSR로 저장**. `first_material[row,col]` 사전계산으로 "플레이트까지 자유?"가 배열 1회 룩업. 각 run 위 빈공간이 외부와 통하는지(`gap_exterior`) union-find로 추적.
- 서포트 형상은 **manifold3d CSG 솔리드**(실린더/구 union → STL) — 우리와 같은 계열.
- 자동 모드에서는 `island_guard.route_without_islands`가 **조립 결과를 재슬라이스해 아일랜드를 찾고 접점을 추가해 재라우팅**(최대 5패스, 크롭 스캔은 판정 불가로 취급하고 전체 스캔으로만 확정).

### 검출
- `downward_contacts`: `n.z < −cos(overhang 45°)` 면의 **무게중심 + 큰 면(면적 > spacing²/2)은 barycentric 격자(최대 64분할)**. 이유: 평평한 밑면은 삼각형 2개뿐이라 중심 1점이면 외곽이 전부 미지지.
- 선택 옵션: `contour_supports`(하향면 하나에만 속하는 엣지 = 오버행 외곽선 샘플), `boundary_supports`(열린 메시 경계, 크롭 절단면용).
- **래스터 아일랜드 탄생**(이전 층과 겹침 0인 컴포넌트)은 **mandatory** — 페인트 차단·드롭 대상 제외. 대표점은 무게중심이 아니라 **중앙값 인덱스의 실제 픽셀**(링·초승달 형태에서 빈 공간 회피).
- `_thin`: spacing 셀당 가장 낮은 후보 1개, mandatory를 앞에 concat해 `np.unique` 첫 등장으로 우선권 확보(벡터화).

### 라우팅 — 3단 폴백 (우리 S-4b-2c와 구조 동일)
0. 밀폐 캐비티 접점 거부("도달·제거 불가", export fail).
1. 수직→플레이트 (`first_material` 룩업).
2. 경사 분기: 반경 `min(2×spacing, 높이)` 창에서 자유 컬럼 탐색, `drop = lateral × tan(pillar_angle 45°, 수평 기준)` < 높이인 것 가까운 순 8개 시도. **충돌 검사는 16점 중심선 샘플링뿐(반경 미고려 — 약점)**.
3. 모델 앵커: 바로 아래 material 상단에 착지. `part_to_part_avoidance`(1=플레이트 우선, 0=길이 경쟁, 중간=비례).
- **짧은 팁**: 갭이 `min_tip(0.3) ≤ gap ≤ tip_length(2.0)`이면 팁 원뿔이 갭 전체를 차지하고 원통 생략. 실측: 세 부품에서 라우팅 실패 절반이 "아래 material까지 1.4mm"였고 이 수정으로 nut 110→195/229, body 516→994/1085 회복. 탐색 폭 8→64는 **0개 회복(측정으로 배제)**.
- 남은 실패 = 0.15mm 분석 격자가 solid로 보는 near-vertical 벽 샘플 → `drop_attached_unroutable`로 프린터 격자 3×3 한 층 아래 점유 시 드롭(경고로 재분류). "휘어짐(sag) 질문은 미해결"이라고 문서에 명시.
- 트리 서포트(기본 off): 수직 플레이트 경로만 KD-tree 반경 클러스터 → 무게중심 트렁크, `trunk_top = min(base_z − lateral×tan)` 로 모든 가지가 각도 충족. **all-or-nothing**(하나라도 충돌하면 그룹 전체 독립 기둥으로 회귀).

### 형상 — 3세그먼트
- 팁: cone(`tip_base_diameter`→`contact_diameter 0.4`, `penetration 0.15`) / cylinder, 선택적 break-point 구 **union**(안 맞으면 클리핑 대신 접점 실패).
- 기둥 반경은 경로 총길이로 **emit 전에 한 번 결정**(짧은 경로는 전 길이 얇게).
- 모델 앵커 하부 커넥터 + **매몰 칼라**: 반경 최솟값의 절반, 높이 1%짜리 실린더를 접합면에 걸쳐 두어 외곽은 그대로 두고 `decompose()` 분리 방지. (우리 assemble-route의 접합 구 대신 쓸 수 있는 최소침습 트릭.)
- model-to-model 소형 기둥은 union이 아니라 **단일 닫힌 메시 직접 구성**(양끝 원뿔 매몰).
- 베이스 8종(plate/none/pad/skate/skeleton/triangle/grid(기본)/hex). MST는 O(n) 메모리 결정론 Prim, Delaunay는 joggle 없이 재현성. 테이퍼는 **실제 층 단위 계단**으로, 밴드마다 플레이트부터 extrude(겹침으로 연결 보장). "hex와 grid는 같은 피치면 개구율 동일" 정량 기록.

### 브레이스 — 있음, 우리 interconnect-pillars와 가장 유사
- `brace_start_height`(기본 파생 = `max_slenderness 40 × 지름`, CHITUBOX 3mm)보다 높은 기둥만, KD-tree **최근접 2개**(전부 연결하면 다공성 부품에서 수만 개 → 강성 없이 형상만 증가), `brace_max_distance`(기본 1.5×spacing).
- 스트럿 반경 = 두 기둥 중 얇은 쪽 × 0.5 (우리는 `min(두 반경)`).
- `brace_spacing`(CHITUBOX 30mm) 간격 반복, 20,000 후보 캡.
- 충돌은 **캡슐 스윕**(셀 대각선 절반 여유) — 분기 라우팅보다 엄격. 단 **서포트-서포트 충돌은 전혀 없음**(필드가 모델만 포함, island_guard 패스 간 갱신도 없음).
- 세장비 초과는 경고. 모든 역학 항목에 `'not a strength proof'` 라벨.

### 검증 게이트
- `support_routes`(라우팅 실패·밀폐 캐비티) = **fail**, 커버리지(하향면 샘플→최근접 접점 거리 > `max_contact_gap`) = fail, 세장비·앵커 하중(면적 배분) = warn.
- 수동 전용 모드에서도 하향면 샘플링을 돌려 커버리지 답변 가능 유지.
- 프리셋 `chitubox-mars5`: 실출력 성공 구성 전사. 팁 0.30/0.80/2.0, 기둥 0.80, 각도 20°(수직기준 70° 변환, 이전 버전 오기 기록), 브레이스 30/3mm, skate ⌀10 두께 0.8 경사 30°. 미측정값(`CHITUBOX_UNSET`)을 명시 목록화.

## 4. 우리(S-4 재설계) 대비 대조표

| 항목 | MazicAlign 현행 | mslicer | Resin-Slicer | VoxelMill |
|---|---|---|---|---|
| 검출 | 층 폴리곤 그래프(아일랜드·오버행) | 메시 면/엣지/국소최저점 | 층 래스터 팽창 차분 + lookback | 메시 하향면 격자 + 래스터 아일랜드 탄생(필수) |
| 점 배치 | 아일랜드 크기 3분기 + 고정 간격 | R2 준난수 | 격자 버킷 첫 픽셀 | 셀당 최저 1개, mandatory 우선 |
| 라우팅 | 1수직→2경사→3앵커 + 0기둥합류 | 모멘텀 하강 | 수직 전용(+옵션 model 앵커) | 0캐비티→1수직→2경사(8후보)→3앵커, 짧은 팁 |
| 충돌 | 삼각형 인덱스 빔 프로브 | BVH 최근접 | 층 원반 래스터 | 컬럼 run CSR(분기는 중심선만) |
| 형상 | STL 파츠 조립 + 접합 구 | 실린더+구 | 층별 디스크 스탬프 | manifold CSG + 매몰 칼라 |
| 브레이스 | 계획 모듈 + strut 조립(완료) | 없음 | 45° 지그재그, 최근접 2 | 최근접 2, 캡슐 충돌, 시작높이/간격 분리 |
| 트리 | 0단 기둥 합류 | 없음 | 없음 | 옵션, all-or-nothing |
| 서포트-서포트 충돌 | (확인 필요) | 없음 | 없음 | 없음 |
| 사후 검증 | verify 스크립트(합성) | 없음 | 관통 테스트(저해상도만) | 재슬라이스 아일랜드 루프 + 커버리지 게이트 |

## 5. 분석 중 눈에 띈 것 (판단은 리드)

1. **VoxelMill의 "짧은 팁" 실측** — 라우팅 실패의 절반이 "아래 material까지 1.4mm" 케이스였다는 진단. 우리 3단 앵커 폴백에 `min_tip` 하한이 있는지 여부가 같은 실패군을 만들 수 있다.
2. **Resin-Slicer lookback** — 층높이가 작을수록 층간 차분 검출이 무력해지는 문제. 우리 layer-graph는 `layerHeightMm 0.05` 고정 가정인지 점검 대상.
3. **VoxelMill 조립 후 재슬라이스 아일랜드 루프** — 서포트까지 포함한 결과에서 아일랜드를 다시 찾아 접점을 추가. 우리 verify는 합성 입력 위주라 "생성 결과 자체의 아일랜드 0" 확인 경로가 없다.
4. **매몰 칼라** — 접합 구 없이 세그먼트 연결을 보장하는 최소침습 트릭(외곽 불변 → 슬라이스 단면 불변).
5. **큰 하향면의 barycentric 격자** — 평평한 밑면이 삼각형 2개일 때 중심 1점 문제. 우리는 층 폴리곤 기반이라 무관하지만 메시 경로를 추가할 경우 해당.
6. **브레이스 "최근접 2개" 상한** — 세 구현 중 둘이 동일 선택. 우리 interconnect-pillars 이웃 수 정책과 비교 가능.
7. 세 구현 모두 **서포트끼리의 충돌**은 검사하지 않는다.
8. mslicer는 GPL-3 — 프루사와 동일하게 **개념만**, 코드 이식 불가.

## 6. AI 판단 (리드 요청으로 추가 — 최종 결정은 리드)

5장 항목을 우리 코드로 재확인한 결과와 함께 순위를 매긴다.

### 재확인으로 정정된 것
- **5-2 lookback → 해당 없음.** 우리 `layer-graph.ts`는 픽셀이 아니라 층 폴리곤과의 연속 거리(`reach = lh/tan θ`)로 판정하므로 "1픽셀 미만" 붕괴가 없다. 폐기.
- **5-1 짧은 팁 → 실패군은 없음, 대신 다른 확인점.** 우리 3단 앵커 하한은 `MIN_SEGMENT_LENGTH_MM = 1e-3`이라 VoxelMill 같은 "너무 가까워서 실패"는 안 생긴다. 다만 갭이 `headLengthMm(1.0)`보다 짧을 때 화살촉 형상이 어떻게 조립되는지는 확인 안 됨(assemble-route 확인 필요).
- **서포트-서포트 충돌 → 우리도 없음** (route/collision 모듈 grep 0건). 네 구현 공통.

### 채택 권고 (효과 큰 순)
1. **조립 결과 재슬라이스 아일랜드 검증** (VoxelMill island_guard 개념). 서포트를 붙인 최종 형상을 우리 슬라이스 파이프라인으로 다시 잘라 아일랜드가 0인지 확인하고, 남으면 그 자리에 점을 추가해 재라우팅. 우리는 슬라이스 워커와 아일랜드 검출이 이미 있어 조립 비용이 낮고, "생성 결과가 실제로 출력 가능한가"를 증명하는 유일한 경로다. 먼저 헤드리스 verify로만 넣고 UI 루프는 뒤로 미뤄도 된다.
2. **전역 3D 씨닝** (VoxelMill `_thin`: spacing 셀당 최저 1점, 필수점 우선). `docs/진단_서포트과다_20260824.md` 6장 ①(전역 3D 중복 제거)과 정확히 같은 처방이고, 벡터화 방식이 그대로 옮겨진다. 진단서 후속 과제와 합쳐 처리.
3. **매몰 칼라** — 조건부. 우리 조립이 파츠를 단순 나열하는지 manifold union까지 하는지에 따라 가치가 다르다. union 경로에서 `decompose` 분리나 슬라이스 단면 끊김이 관찰될 때만.

### 보류
- **VoxelMill 트리 서포트** — 우리 0단 기둥 합류가 이미 같은 역할. all-or-nothing 방식은 오히려 후퇴.
- **큰 하향면 barycentric 격자** — 메시 검출 경로를 추가하기 전까지 무관.
- **브레이스 최근접 2개 상한** — 우리 interconnect-pillars 정책과 비교만. 실물 테스트 전에는 바꿀 근거 없음.

### 폐기
- **mslicer 전부** — GPL이고 미완. R2 준난수 샘플링은 아이디어로만 기억.
- **Resin-Slicer 래스터 스탬프 방식** — 서포트 메시 없이 슬라이스에 찍는 구조라 우리 아키텍처(STL 조립·내보내기)와 맞지 않음. 지그재그 브레이스와 18° 하한도 래스터 디스크 스택 전제라 우리 형상 조립에는 이유가 없다.
