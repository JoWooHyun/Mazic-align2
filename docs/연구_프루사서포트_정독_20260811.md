## 2. 전체 파이프라인 (DefaultSupportTree::execute)

```
① PINHEADS  : 중복점 제거(0.1mm) → 법선 계산 → 핀헤드 방향 최적화(45° 포화, 실패 시 가는 머리 폴백)
② CLASSIFY  : 각 헤드에서 수직 하향 빔 검사 → "지면 직행 가능" / "모델 위" 분류
              + 지면 직행 헤드를 클러스터링(2D 거리 < 2×base_r && 3D < max_bridge)
③ ROUTING_GROUND   : 클러스터 중심(centroid) 1개만 지면 기둥 생성, 나머지 멤버는
              그 기둥에 경사 다리로 합류(connect_to_nearpillar). 실패 시 개별 기둥.
④ ROUTING_NONGROUND: 모델 위 헤드 폴백 순서 —
              (1) 근처 기둥에 다리 합류 → (2) 지면 루트 탐색 → (3) 모델 표면 앵커(뒤집힌 핀헤드)
              → (4) 전부 실패 시 그 점 무효화 + 경고 로그
⑤ CASCADE_PILLARS  : 기둥 이웃 연결(아래 5절)
⑥ MERGE     : 부품 메시 병합(+캐시)
```

**우리 S-4b-2 대응**: 3단 폴백=④, 충돌회피=빔 검사(전 단계 공통), 기둥연결=⑤.
**핵심 발견 — 기둥 공유(③)가 기본 구조**: 프루사는 점마다 기둥을 세우지 않는다.
클러스터당 기둥 1개+다리 합류가 기본. **우리 1,300개 문제(B-3)의 정공법이 이것.**

## 3. 충돌 회피 (beam_mesh_hit)

- 막대 = 두 구(Ball)를 잇는 원뿔면. 표면 둘레 링에 광선 N개(기본 8, 핀헤드 16 — "8이면 거의 되나
  드문 충돌, 16은 60% 느림") + 안전거리 sd 오프셋 → **최소 히트 거리** 채택.
- **내부 시작 처리**: 히트가 is_inside면 — 관통 거리가 2r+sd보다 크면 "점이 모델 내부" 판정(즉시 실패=거리0),
  아니면 관통 지점 밖으로 나가 재발사. (화살촉 0.2 침투 전제에서 필수 로직)
- 우리 채택: 링 광선 8(기둥)/16(접점 주변), sd=0.5mm(설계값), 내부 재발사 포함.

## 4. 폴백 상세 (실사용 경로 = Legacy 쪽)

- **connect_to_ground**: 먼저 주어진 방향(수직)으로 빔 검사. 막히면 —
- **걸어나가기 루프(create_ground_pillar / check_ground_route 단순판)**:
  방위각은 유지, 극각만 45°로 포화한 경사 방향 d로 **t += r(반경 단위)씩 전진하며 매 스텝
  "그 지점에서 수직 하향 빔이 뚫리는가"를 검사**, 뚫리면 거기서 기둥. 상한 = max_bridge_length와
  경사 기하 한계 min. → **우리 2단(경사 다리)의 구현 모델로 이것을 채택** (deepsearch 최적화판은 참고만).
- 방향 탐색 실패 시 (극각,방위각) 2변수 탐색(시드 고정=결정적) 후 재시도 → 그래도 실패면 다음 폴백.
- **모델 앵커(connect_to_model_body)**: classify 때 저장한 하향 히트 지점에 뒤집힌 핀헤드(Anchor) 부착.
  꼬리 길이 h = sin(히트각, 최소 45°)×헤드폭, 짧은 기둥+앵커. 실패 시 점 무효화+통지(조용히 넘어가지 않음).
- **가는 기둥 승격(search_widening_path)**: 반경<기준 기둥이 20×r보다 길면 DiffBridge(굵어지는 다리)로
  기준 반경까지 넓혀 지면행. (좌굴 방지 — 굵히기 쪽 메커니즘)

## 5. 기둥 연결 (interconnect_pillars)

- H1(solo 최대 높이) 초과 → 이웃 1개 필요, H2 초과 → 2개. (우리 15/35mm 규칙의 원형)
- 이웃 후보: 반경 비례 거리 max_d = link_dist × r/기준r 내, 가까운 순. 페어 중복은 pairhash로 방지.
- **지그재그**: 두 기둥 사이 수평거리로 zstep=d×tan(45°) 계산, sj/ej를 교대로 내려가며 다리.
  다리마다 빔 충돌검사 통과 시에만 추가. 거리>2×base_r면 X자 교차(cross) 추가(dynamic 모드).
- 연결 카운트 조건: 짧은 쪽/긴 쪽 높이비 50% 이상일 때만 "연결됨"으로 인정.
- **외톨이 기둥 구제**: 연결 못 찾으면 주변 20방향×반경 2×base_r 위치에 **보조 기둥을 새로 세워** 연결
  (다리 과다 기둥은 3개까지). — 우리 1차 범위에서는 생략 가능(후속).
- 기둥당 다리 수 상한(max_bridges_on_pillar), 지면 근처 다리 금지(최소 4×r 위).

## 6. 형상 조립 (Builder/Mesher) — B안과의 대응

- 프루사도 **부품 목록(Head/Pillar/Bridge/Junction/Pedestal/Anchor)을 부기 후 일괄 메시화**.
  다리=단위 실린더를 쿼터니언(FromTwoVectors)으로 회전 배치 — **우리 assemble-core '두 점 잇는 막대'와 동일 개념.**
- Junction(작은 구)을 모든 꺾임/합류점에 삽입 — 다리·기둥 접합의 단면 연속성 확보.
  **우리도 경사다리 꺾임점에 구(junction) 부품 삽입 필수** (S-4b-1 파단 이슈의 일반화).
- 핀헤드 = 구 2개의 "보이는 부분만" + 접선 로브(우리는 근사 조립이라 이 최적화는 불요).
- Pillar는 "끝점+높이"만 갖는 수직 전용, 경사는 전부 Bridge — 우리 부품 구분도 동일하게 유지.

## 7. S-4b-2 스펙 반영 요약 (설계서 4장 대비 추가/수정 제안)

1. 폴백 순서를 프루사식으로: **근처 기둥 합류 → (수직→경사 걸어나가기) 지면행 → 표면 앵커 → 무효화+통지**.
   (설계서의 1·2·3단과 같되 "근처 기둥 합류"가 0단으로 추가되는 셈 — 기둥 수 절감 핵심)
2. 경사 다리 = 반경 단위 걸어나가기 루프(결정적, 최적화 라이브러리 불요).
3. 충돌검사 = 링 광선 + 내부 재발사 + 안전거리. 결과 캐시/공간 인덱스(기둥 끝점)로 이웃 질의.
4. 기둥연결 = H1/H2 이웃 1/2개, zstep=tan(45°), 다리마다 충돌검사, 높이비 50% 규칙.
5. 점 전처리 = 0.1mm 중복 제거 + 클러스터 기둥 공유(B-3 완화와 직결).
6. 실패 점은 조용히 버리지 말고 카운트 통지(프루사도 경고 로그).
