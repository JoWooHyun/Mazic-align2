### MED-1. 검출 층높이가 슬라이스 패널과 영구 단절 (S-2 워커화의 조용한 회귀) — 수정 필요

- 위치: `pages/viewer/hooks/useDentalWorkflow.ts:223`
  — `layerHeightMm: detectParams.layerHeightMm ?? layerHeightMm`
- 사실관계: `useDetectParamsStore.ts:34`가 `layerHeightMm`을 **항상 0.05로 정의**하고,
  이 키를 바꾸는 `setParam` 호출은 저장소 전체 0건(DetectParamsPanel도 "슬라이스 패널 소유"라며
  의도적으로 미노출). → `??` 우변(슬라이스 프리뷰 층높이)은 **절대 도달하지 않는 사문**.
  워커화 이전 코드는 슬라이스 값을 직접 썼으므로 동작 회귀다.
- 실패 시나리오: 슬라이스 층높이를 0.1mm로 바꿔도 재설계 검출은 항상 0.05mm 기준(층 수 2배)으로
  돌아 통계·검출 결과가 화면 설정과 어긋남. C-3(검출각 단일 출처) 때 잡았던 것과 같은 원칙 위반.
- 같은 사문 패턴: `components/babylon/redesign-detect-actions.ts:163`(sync 경로 — 현 UI 호출자 없음).
- 수정 방향(소규모): `DetectParams`에서 `layerHeightMm` 제거(또는 기본값 `undefined`)하고
  워커 요청에 슬라이스 값을 직접 전달. **→ 별도 fix PR로 처리 (리드 승인 후 착수)**
