# MazicAlign v2 기능 목록 — 코드 실측 (2026-09-28)

- 작성: 2026-09-28, AI 전수 조사 (`frontend/src/features/v2` + `App.tsx`). 코드에서 확인된 것만 적음.
- 목적: 리드 질문 "지금 슬라이서 기능이 뭐가 있나"에 대한 답. `docs/계획_11월데모_20260923.md` §2 목록의 정정본.
- 상태 표기: **정상** / **disabled** / **개발용 노출** / **코드만**(UI 미연결) / **단축키 전용**(버튼 없음)

## 한눈 요약

- 큰 빈칸: CTB 내보내기 disabled, `.mzalign` 프로젝트 저장·열기 코드만, 프로젝트 이름 변경 없음, 모델 크기(mm) 표시 없음, 프로파일 JSON 내보내기 없음.
- 개발용 노출: Dental 탭 "서포트 재설계 (검증)" 묶음. 그 안의 "서포트 생성(재설계)"가 실제 저장 경로라 **자동 서포트 진입점이 3개**.
- undo/redo 는 단축키 전용. STL 추가·삭제·붙여넣기·복제·dental 칠하기는 undo 불가. Select 모드 Delete 는 확인창 없음.
- 서포트·검출 파라미터·레이어 두께·dental 칠한 결과는 **새로고침하면 사라짐**. 저장되는 건 프린터 프로파일(localStorage)뿐.
- 영어 라벨 다수: 모드·기즈모·카메라 버튼, 프리셋, 프로젝트 목록 화면 전체.
