## 1. B-13 (PR #45) — 축 Z-up 표기 ★ 이번 핵심

프린터 관례대로 **Z가 높이**로 보이게 한 것. CHITUBOX 캡처 ①과 대조.

| # | 확인할 것 | 기대 결과 |
|---|---|---|
| 1-1 | 우하단 **범례** | "Z (위)" 로 표시 |
| 1-2 | 원점 **축 라인 색** | 화면상 **위로 가는 선이 파랑(Z)** |
| 1-3 | 모델을 **위로** 올리기 | **Z 값**이 커진다 (예전엔 Y였음) |
| 1-4 | 플레이트 위에서 **평면 이동** | X / Y 값이 변한다 (Z는 그대로) |

### ★★ 1-5. 회전 부호 — 가장 중요

**Z에 +90° 입력** → 도는 방향(시계/반시계)이 기대대로인가?
X, Y도 각각 +90°씩 넣어 확인.

> 왜 중요한가: 축 매핑을 잘못하면(반사) **+90°를 넣었는데 −90°로 도는** 버그가 난다.
> 검증 스크립트로 걸러냈지만 실물에서 최종 확인이 필요하다.

### ★★ 1-6. 복합 회전 — 두 번째로 중요

**X로 한 번 돌린 *뒤*, 이어서 Y로 또 돌려보기.**

> 왜 중요한가: 원래 계획했던 방식이 **단축 회전에서는 우연히 맞고 복합 회전에서만 틀리는**
> 종류의 오류였다. 구현 중 발견해 고쳤지만, 눈으로 확인할 곳이 정확히 여기다.
> 한 축만 돌려보면 이 문제는 절대 안 보인다.

|---|---|---|
| 1-7 | **±90° 버튼** | 라벨과 실제 도는 축이 일치 |

CHITUBOX 캡처 ②③④와 대조.

| # | 확인할 것 | 기대 결과 |

| **2-2 ★** | **회전 슬라이더를 잡고 *천천히 끄는 동안*** POSITION 숫자 | **흔들리지 않는다.** 손 뗄 때 값이 튀지 않는다 |

## 3. B-1 + B-11 (PR #43) — 변형 시 서포트 무효화

재설계 서포트(Dental 탭에서 생성한 것)가 모델 변형을 따라가면 기둥이 기울어 출력 불가 →
CHITUBOX처럼 **삭제 + 안내**하되, **순수 수평 이동은 예외로 유지**한다.

준비: 모델 로드 → Dental 탭에서 재설계 서포트 생성

| # | 확인할 것 | 기대 결과 |
|---|---|---|
| **3-1 ★** | 모델 회전 → **즉시(주저 없이) Ctrl+Z** | 재설계 기둥이 **전부** 돌아온다 (개수도 생성 시와 동일) |
| 3-2 | 회전 → Ctrl+Z → Ctrl+Shift+Z → Ctrl+Z | redo에서 재설계 점만 사라지고 world 서포트는 유지 / 마지막 undo에서 재복원 |
| 3-3 | 재설계 점 **수십 개** 만들고 회전 | 삭제가 **한 번에** 사라짐 (하나씩 깜빡이며 사라지면 안 됨), 배너 개수 정확 |
| 3-4 | **순수 수평 이동만** 하기 | 기둥이 **삭제 안 되고** 모델을 따라간다, 배너도 안 뜸 |
| 3-5 | 프로젝트 내보내기 → 같은 프로젝트에 **overwrite로** 다시 가져오기 | 서포트 개수가 그대로 |

> **3-1이 왜 핵심인가**: "실수로 회전 → 즉시 되돌리기"가 이 기능의 존재 이유다.
> 1차 검수에서 여기서 **서포트가 전부 소실되는** 결함이 나왔다(조용히 실패).
> **회전하자마자 바로** 눌러야 한다 — 여유 있게 누르면 문제 구간을 지나쳐 의미가 없다.

> **3-5가 왜 필요한가**: 내부적으로 저장 방식을 `add`→`put`으로 바꿨는데,
> 그 변경이 지나가는 **유일한 import 경로**가 이것이다.

## 5. 함께 봐주시면 좋은 것 (#44 컨펌 안건)

회전 후 POSITION **Y가 CHITUBOX처럼 0이 되지 않습니다**(우리는 모델높이의 절반).
CHITUBOX의 0은 "바닥 기준 + **회전 후 자동 안착**"의 결과로 보입니다.

→ **CHITUBOX에서 "바닥에 붙이기" 체크박스를 켰을 때와 껐을 때 회전 후 좌표가 어떻게 다른지**
확인해주시면, A(현행 유지) / B(자동 안착 추가) / C(Y만 바닥 기준) 중 무엇으로 갈지 판단할 수 있습니다.
**AI 권고는 A 유지 + B는 별건 검토**입니다.
