## 0. 규격서 이해 (요약 — 틀리면 여기서 바로잡을 것)

Task0 는 **"FDM 과 똑같이 움직이는 top-down 레진 프린터"** 다. 필라멘트 자리에 시린지 레진 2종(T0=레진A, T1=레진B)이
있고, 층 경계에서만 Task0 가 **블레이드 평탄화 → LED 노광 → Z 이동**을 끼워 넣는다. 슬라이서(MazicAlign)는
**층 안의 도포 경로(G1 XY+E)** 만 책임지고, 층 경계는 **주석 마커**로 알려주기만 하면 된다.

슬라이서가 지켜야 할 것 (규격서 §2~§7):

| 구분 | 규격 |
|---|---|
| 필수 마커 | `; EXECUTABLE_BLOCK_START` (이전 전부 무시), `;LAYER_CHANGE` (층 경계), 직후 `;Z:x.x` / `;HEIGHT:x.x` |
| 파일 선두 | `G90` → `M83` → `T0` (호밍·준비 동작 **넣지 않음** — PRINT_START 매크로 위임 패턴) |
| E 모드 | **M83 상대 E 권장**, `G92 E0` 층마다 1회 권장, `M400` 층 경계 동기화용 |
| E 정의 | E = **시린지 플런저 이동 mm**. `E = 거리 × 도포폭 × 층높이 ÷ K`, K(플런저 1mm당 mm³) **미정** |
| 리트랙션 | 음수 E 허용(흘러내림 방지). 거리·속도 미정 |
| 속도 | 도포 ≤F1800 / 트래블 ≤F6000 (초안, 미정). 드라이런은 F300 강제 |
| 금지/무시 | 히터(M104/109/140/190)·팬(M106/107)은 무시되지만 **넣을 이유 없음**. 블레이드 명령은 슬라이서가 쓰지 않음 |
| 듀얼 소재 | **층 안에서 T0→T1 전환 허용** (듀얼컬러 FDM 방식). 서포터=T0 먼저, 출력물=T1 나중. 전환 전 리트랙션 후 `T0`/`T1` 한 줄 |
| 기계 | 베드 X 0~150 / Y 0~85 / Z 0~2000 mm |
| 패키지 | `job.zip`(run.gcode + exposure.json + layers/*.png …) — **Phase 5, 지금은 대상 아님** |

한 줄 요약: **마커 3종 + 헤더/푸터 정리 + 상대 E + 층 내 T0/T1 분리 + 150×85 베드**.
E 상수 K·리트랙션·속도 한계는 실험 후 채워지므로 **설정값으로 열어 두고 기본값은 임시**로 간다.

## 2. 설계 결정 (리드 확인 포인트 ★ 표시)

**D-10. 도포 패턴 — ✅ 확정(2026-10-02 리드)**: 층 전체 서펜타인 0° 줄 채움(행 간격 = 도포폭 w, 경계에서 w/2 안쪽까지) + 테두리 없음 + 행 간 L자 이동, 파킹 (0,0) 에서 멀어지는 +Y 단조. **얇은 부분 채움**: 행이 덮지 못한 부분(폭 w~2w 띠, w 미만 벽·링)은 중심선 한 줄, 아주 작은 섬은 점 도포. 검사 기준은 규격서 v0.3.1 §3 (a)(b)(c) + 협의 §22 (d). 근거 시뮬레이션 `docs/references/sim-coverage-20261002.py`.

**D-1. 플레이버 스위치 도입** — `FdmSettings.gcodeFlavor: 'task0' | 'marlin'`.
`marlin` 은 현 산출물을 **바이트 그대로** 보존하는 회귀 기준(규칙 5), `task0` 가 신규 경로.
헤더/푸터/층 프리앰블/E 모드/도포·트래블 속도만 플레이버가 갈라지고, 벽·인필·갭필 기하는 공유한다.
★ **기본값은 `task0`** 로 제안 — 팀에 FDM 프린터가 없고 최종 목표가 이 기계다. 리드가 원하면 `marlin` 기본 유지.

**D-2. E 는 상대(M83)** — 생성기는 지금 `currentE` 누적 절대값을 찍는다. task0 에서는 세그먼트 델타를 찍고
`currentE` 는 통계용으로만 유지. 리트랙트 `E-r` / 언리트랙트 `E+r` 도 델타. 층 시작 `G92 E0` 은 규격 권장이라 유지.

**D-3. 층 내 2패스** — `getFdmSliceInput` 이 mesh 마다 `role: 'model' | 'support'` 를 붙여 넘기고, 워커의
`generateFdmGcodeFromTriangles` 가 층마다 **서포트 폴리곤(T0) → 모델 폴리곤(T1)** 순으로 `generateLayer` 를 2회 호출.
빈 패스는 T 라인도 찍지 않는다(단, 첫 층 헤더의 `T0` 는 항상).
**전환 시퀀스(9/29 Task0 합의): `G1 E-r` → `T1` → `G1 E+r` — 리트랙트·언리트랙트 둘 다 슬라이서.** 매크로는 파킹+퍼지만 하고 E 순변화 0 을 보장. r 은 재료 프로파일 값. test_2.gcode 로 실기 검증된 패턴.
~~겹침 차집합은 하지 않는다~~ → **9/29 정정: 우선순위 차집합(B > A > 서포트) + 경계 여유 + 부스러기 제거**. 상세 `docs/계획_하이브리드슬라이서설정_20260928.md` §5-3. 단 T0-2 1차 PR 은 서포트=A/모델=B 2패스 골격까지만 하고, 차집합·경계 여유는 하이브리드 P4(d) 에서.
★ 기본 매핑 서포트=T0/출력물=T1 은 규격 §7 그대로. 나중에 "단일 소재" 모드가 필요하면 `materialMode: 'dual'|'single'` 로 확장.

**D-4. Z 이동 — ✅ 확정(9/29)** — 층 시작 절대 `G1 Z{z}` 1줄을 **슬라이서가 쓴다. Task0 는 Z 를 넣지 않는다.** 리트랙트 z-hop 은 task0 기본 0.
플랫폼 영점·T1 Z 오프셋은 Task0 가 `SET_GCODE_OFFSET Z` 로 처리 — 슬라이서 Z 는 순수 (N+1)×lh (D-9).
**⚠️ 필수 불변식 (9/29 Task0 §10-2 — 노광 후 복귀 전 +Z 리프트 때문)**: Task0 는 매 층 노광 뒤 플랫폼을 +3mm 리프트한 상태로
다음 블록을 보낸다. 그래서 task0 플레이버는 (1) **모든 `;LAYER_CHANGE` 블록의 첫 이동 명령이 `G1 Z{(N+1)×lh}`** — XY·E·T 보다 먼저
(리프트 상태에서 도포하지 않도록), (2) **빈 층도 마커 + Z 출력, 층 건너뛰기 금지**, (3) **이전 층과 같아 보여도 중복 제거 금지**.
현 생성기는 이미 매 층 첫 줄에 `G0 Z` 를 쓰고 빈 층도 출력한다(gcode-generator.ts:113) — task0 에서는 `G1 Z` 로 쓰고 이 성질을 보존.
`fdm-gcode.ts` 의 `if (sampleY > range.yMax) break;` 가 task0 층 수(ceil(topY/lh))를 줄이지 않게 할 것.
(4) **Z 줄은 순수 Z 줄** — 같은 줄에 X·Y·E 를 섞지 않는다. **F 는 붙이지 않는다(✅ 확정, Task0 §12)**: Task0 실출력 모드가 순수 Z 줄의 F 를
Z 속도 설정(기본 5mm/s)으로 덮어쓴다. X·Y·E 가 섞이면 덮어쓰기가 적용되지 않아 직전 F(최대 F6000)로 나가고 max_z_velocity 25mm/s 로만 잘린다
(F 는 modal — "Klipper 가 알아서 제한"은 안전 속도를 보장하지 못한다는 Task0 정정).

**D-9. 층 번호·Z 규약 — ✅ 확정(9/29, 신규)** — task0 플레이버는 **마스크 규약으로 통일**하고 marlin 플레이버는 바이트 보존.
| | task0 플레이버 | marlin (회귀 기준, 변경 없음) |
|---|---|---|
| 층 수 | ceil(topY / lh) — 마스크와 동일. topY = 플레이트 0 기준 씬 최고점(서포트 포함) | ceil(h/lh) + 1 |
| 층 N 단면 | (N + 0.5) × lh 에서 자름 — 마스크 PNG 와 **같은 평면** | N × lh + ε |
| `;Z:` = `G1 Z` | **(N + 1) × lh** — 층 윗면 = 블레이드 평면 깊이. 첫 층 Z = lh | N × lh |
| `;HEIGHT:` | lh | — |
근거: Task0 실출력 워커 식 `z = z_offset + (idx+1)×lh`(print_worker.py:457), 표준 FDM 슬라이서 관례. ⚠️ 이 결정으로 `fdm-gcode.ts` 의 층 루프가 플레이버로 갈라진다 — marlin 경로 SHA-256 불변이 T0-1 수용 기준 (d).
참고: marlin 의 "첫 층 Z=0" 은 실제 FDM 에선 노즐이 베드에 닿는 값이다(Task0 지적). 팀에 FDM 실기가 없으므로 회귀 기준으로만 유지하고 **실제 FDM 출력 용도로는 쓰지 않는다.**

**D-5. E 상수 K** — `FdmSettings.syringeMm3PerMm`(플런저 1mm당 mm³) 신설. 규칙 6(기본값 단일 소스)대로 `DEFAULT_FDM_SETTINGS` 한 곳.
★ 임시 기본값은 **2.405** (필라멘트 단면적과 동일) — 즉 K 확정 전까지 E 수치는 지금과 같다. 시린지 내경 확정 시 이 한 줄만 바꾼다.
(예: 내경 Ø10 시린지면 K ≈ 78.5)

**D-6. 속도** — `travelSpeed`(mm/s) 신설. task0 기본: 도포 30(F1800) / 트래블 100(F6000) / 리트랙트 40 — 전부 규격 초안 상한.
드라이런은 어차피 F300 강제라 실기 첫 검증엔 영향 없음.
