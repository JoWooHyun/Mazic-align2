## 수정한 것

### 🔴 H3. 출력영역 검사가 **새로 불러온 모델에 안 걸린다** (기능 자체가 목적 미달성)

`useFileMeshSync` 는 메쉬를 `Promise.all(...).then(...)` **안에서** `meshMapRef` 에 등록한다.
`useBuildVolumeCheck` 는 같은 커밋에서 `[files]` 로 돌기 때문에, 새 파일은 `meshMapRef.get(id)` 가
`undefined` 라 **`continue` 로 건너뛴다.**

→ **크기 초과 STL 을 올려도 경고가 안 뜬다.** 이미 영역 밖이라 사용자가 모델을 건드릴 이유가 없으니,
C-2 기능이 정작 **제1 사용 사례에서 침묵**했다.

**수정**: `useFileMeshSync` 에 `onMeshesLoaded` 콜백 추가 → `BabylonScene` 이 `meshLoadTick` state 로
받아 `useBuildVolumeCheck` deps 에 전달. 로드가 실제로 끝난 뒤 재검사한다.

### 🔴 H2. 휠 옵저버 — 관성 잔량이 얼어붙어 B-28 이 재발할 수 있었다

Babylon `_zoomToMouse` 는 커서 방향 팬을 `_inertialPanning` 에 **누적**하고, 그 값은 `checkInputs()`
안에서만 빠져나간다. 그런데 `checkInputs` 는 `zoomToMouseLocation` 이 꺼져 있으면 **즉시 return** 한다.

→ 줌인 관성이 남은 채 줌아웃으로 넘어가면 잔량이 그대로 **동결**되고, 다음 줌인에서 플래그가 켜지는
순간 낡은 벡터가 `camera.target` 에 한꺼번에 적용돼 시점이 튄다. **B-28 수정이 더 작은 B-28 을
남긴 셈.** (리드가 "아직은 발견 못했다"고 한 것과 모순되지 않는다 — 재현 조건이 좁다.)

**수정**: 플래그를 끌 때 `_inertialPanning` 과 `inertialRadiusOffset` 을 0 으로 비운다.
추가로 옵저버를 `wheelObserverRef` 로 잡아 `disposeScene` 에서 명시 제거(이 폴더 규약 준수).

### 🔴 H1. `useAlignFloorHover` 가 **매 렌더마다** teardown·재등록

`ctx` 를 deps 에 넣었는데 `useSceneRefs` 는 **매 렌더 새 객체 리터럴**을 반환한다.
→ 부모가 리렌더될 때마다(슬라이스 프리뷰 틱 등) 옵저버 제거·재등록 + 머티리얼 생성·폐기가 반복되고,
**호버 중 데칼이 깜빡인다.** CLAUDE.md 규칙 7이 "반복 사고 유형"으로 지목한 바로 그 클래스.
이 폴더의 다른 훅은 전부 값 deps + eslint-disable 을 쓴다.

**수정**: `ctx` 를 deps 에서 제거하고 형제 훅과 같은 규약으로 통일.

### 🟠 M3. `onIssues` 스테일 클로저 함정 (잠복)

deps 에서 제외돼 **첫 렌더의 콜백을 영구 캡처**한다. 지금은 호출부가 `setVolumeIssues`(안정)라
무해하지만, 같은 JSX 블록의 다른 prop 들처럼 인라인 화살표로 바뀌는 순간 조용히 낡은 클로저를
계속 부른다. **수정**: `onIssuesRef` 미러링(이 폴더의 15개 콜백이 이미 쓰는 방식)으로 구조적 차단.

### 🟠 M2. `useBuildVolumeCheck` cleanup 부재
경고 박스를 "다음 실행 맨 앞"에서만 지워, 마지막 실행 이후엔 남았다. `scene.dispose` 가 회수하므로
누수는 아니나 정리 규약과 어긋남. **수정**: cleanup 함수 추가.

### 🟠 M1. 호버 데칼이 STL 삭제 시 허공에 남음
`MeshBuilder.CreateDecal` 은 `useLocalComputation` 없이는 부모를 설정하지 않아 **자유 메시**가 된다.
호버 중 해당 STL 이 삭제되면 노란 조각이 남는다. `useDentalBrush` 는 "데칼은 STL child" 를 전제로
정리한다. **수정**: `decal.parent = pick.pickedMesh`.

### 🟠 M4. 정점당 `Vector3` 할당
`computeAlignFloorTransform` 이 `TransformCoordinates` 로 **정점마다 새 Vector3 를 할당**(10만 정점 =
10만 개). 두 파일 건너 `worldVertexAabb` 는 이미 `...ToRef` 를 쓴다. **수정**: `TransformCoordinatesToRef` + 재사용 버퍼.
