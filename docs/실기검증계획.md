# 실기 검증 계획서 — "프린터 앞 반나절"

- 작성: 2026-07-09 (날짜 확정 시 이 문서로 진행)
- 목적: 코드만으로 검증 불가능한 3+2건을 실제 장비로 확정 (감사 A7·A8 + 첫 레이어 + 품질 2종)
- 소요: 약 반나절 (출력 대기 포함). 참석: 조우현 + 장비 다룰 줄 아는 1인 (유승제 또는 지현규 권장)

## 준비물 체크리스트

- [ ] 레진 프린터 (기종명 기록: ______) + 레진 + 세척/경화 장비
- [ ] USB 메모리
- [ ] PC에 **UVTools** 설치 (무료, CTB 파일 검사 도구 — 설치 링크는 검색 "UVTools github")
- [ ] G-code 확인용: 브라우저에서 **ncviewer.com** (설치 불요)
- [ ] 테스트 모델: `STL Sample/` 6개 (이민정/홍연제) + 방향 구분용 비대칭 모델(L자 또는 글자 모델 — AI가 사전 생성 제공 가능)
- [ ] **테스트 빌드**: AI에게 "실기 테스트 빌드 준비해줘" → .ctb 버튼이 활성화된 브랜치를 준비해 드림 (현재 UI에서 비활성 상태라서)

## 검증 항목 (순서대로)

### ① CTB 실기 판독 (감사 A8) — 가장 중요
1. 테스트 빌드에서 소형 모델(cylinder류) 슬라이스 → .ctb 내보내기
2. **UVTools로 열기**: 레이어 이미지가 정상 표시되는지, 프로파일의 노광/리프트 값이 입력대로 보이는지 (PR #8·#10의 값 반영 확인)
3. USB로 프린터에 → **프린터가 파일을 인식·미리보기하는지**
4. 소형 출력 1회 → 성공 여부
- **판정**: 3까지 성공 = .ctb 버튼 정식 활성화 / UVTools에서 깨짐 = 어느 필드가 깨졌는지 스크린샷 → AI가 인코더 수정
- ⚠️ ChiTuBox 강제종료 이력이 있는 부분 — UVTools 결과가 우선 기준

### ② 마스크 ↔ G-code 좌표 방향 (감사 A7) — 하이브리드의 전제
1. **비대칭 모델**(좌우 구분되는 것)을 슬라이스
2. 마스크 ZIP의 중간 레이어 PNG를 열어 방향 확인 (글자/L자가 어느 쪽인지 기록)
3. 같은 모델 G-code를 ncviewer.com에 넣어 XY 방향 확인
4. 실기로 마스크 출력 → 실물의 방향 확인
- **판정**: 마스크·G-code·실물 3자의 좌우가 일치하는가? 불일치 시 어느 쪽이 뒤집혔는지 기록 → AI가 코드에서 방향 상수 고정 (2노즐에서 두 좌표계가 한 기계에서 만나므로 필수)

### ③ FDM 첫 레이어 (PR #22 후속)
1. G-code 첫 층(`; layer 0`)에 실좌표 존재 확인 (메모장으로도 가능)
2. ncviewer에서 첫 층이 바닥(Z≈0.05)에서 시작하는지
- **판정**: v1에서 겪었던 "첫 층 누락 → 접착 실패"가 재발하지 않는 상태 확정

### ④ dental 품질 (지현규 회귀와 묶음 — 본인 참석 시)
1. STL Sample로 브러쉬→마진→아일랜드→자동 서포트 전체 워크플로우
2. 마진 라인이 v1과 같은 품질인지 육안 (PR #14 회귀의 실물 버전)
3. 출력 후: 서포트가 아일랜드를 실제로 받쳤는지, 마진 침범이 없는지
- **판정**: 지현규 승인 = Phase 2 품질 보증 완결

### ⑤ 예상 시간 정확도 (보너스)
- 출력 시작 시 화면의 예상 시간 기록 → 실제 소요와 비교 (PR #6 검증. ±10% 이내면 합격)
